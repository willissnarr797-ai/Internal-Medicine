## 通用十问

无论何种疾病，最终都要能够闭卷回答：

1. 它是什么，诊断边界在哪里？
2. 如何分类、分型、分期或分层？
3. 主要病因、危险因素和易感人群是什么？
4. 发病机制如何解释病理改变？
5. 核心症状、体征及并发症是什么？
6. 哪些检查用于筛查、确诊、分型和严重度评估？
7. 诊断标准是什么，最关键的鉴别诊断是什么？
8. 治疗目标、急性处置和长期策略分别是什么？
9. 如何判断疗效、预后并安排随访？
10. 如何用一句话、机制图和决策树复述该病？

## 专业框架

### 感染性疾病

- 适用条目：48 个。
- 学习主线：病原体与传播/感染场景 → 宿主危险因素 → 感染部位与发病机制 → 临床综合征 → 病原学证据与严重度 → 经验性处置逻辑 → 目标性治疗逻辑 → 并发症、隔离与预防。
- 核心抓手：把病原体、宿主和感染部位连成一条因果链，并区分病原学确诊与经验判断。
- 最小输出：画出“暴露/宿主—病原体—器官损伤—诊断证据—处置—预防”流程图。

### 肿瘤性疾病

- 适用条目：36 个。
- 学习主线：组织起源与病理类型 → 危险因素和癌前状态 → 分子特征 → 局部与全身表现 → 确诊路径 → 分期/危险分层 → 分层治疗 → 疗效、复发与预后。
- 核心抓手：先定病理，再定分期和分子分层，最后把治疗与分层一一对应。
- 最小输出：制作“病理—分期—分子标志物—治疗选择—随访终点”五列表。

### 心律失常

- 适用条目：31 个。
- 学习主线：心电图识别 → 起源与电生理机制 → 病因和可逆诱因 → 血流动力学稳定性 → 急性处理目标 → 卒中/猝死等风险分层 → 药物、消融或器械策略 → 随访与复发预防。
- 核心抓手：先用频率、节律、P波、QRS和房室关系完成识图，再决定是否需要紧急处置。
- 最小输出：输出一张心电图判读卡和一棵“稳定/不稳定—急性/长期”决策树。

### 心血管与血流动力学疾病

- 适用条目：97 个。
- 学习主线：解剖定位 → 危险因素/病因 → 血流动力学与病理生理 → 症状体征 → 心电图/标志物/影像 → 严重度与风险分层 → 药物—介入—外科阶梯 → 二级预防与随访。
- 核心抓手：把解剖改变转换为血流动力学后果，再解释症状、体征和检查结果。
- 最小输出：画一条“结构异常—压力/容量变化—症状体征—检查—治疗靶点”机制链。

### 呼吸系统疾病

- 适用条目：53 个。
- 学习主线：解剖部位与病变性质 → 病因/表型 → 通气、换气与气体交换 → 症状体征 → 肺功能/影像/血气 → 诊断与鉴别 → 急性期与稳定期管理 → 并发症、康复和随访。
- 核心抓手：抓住气道、肺泡、间质、血管或胸膜定位，并用肺功能、影像和血气相互印证。
- 最小输出：制作“定位—功能障碍—关键检查—严重度—急性/长期管理”表。

### 消化与肝胆胰疾病

- 适用条目：66 个。
- 学习主线：器官与层次定位 → 病因和危险因素 → 病理生理 → 症状与体征组合 → 实验室/影像/内镜 → 诊断和鉴别 → 并发症 → 治疗、营养与监测。
- 核心抓手：先完成器官定位，再用实验室、影像和内镜建立证据链，最后处理并发症。
- 最小输出：输出“定位线索—确诊检查—并发症—治疗入口”四栏卡片。

### 肾脏疾病

- 适用条目：46 个。
- 学习主线：肾小球/小管/间质/血管定位 → 临床综合征 → 病因与免疫机制 → 尿液、肾功能和血清学 → 影像与肾病理 → 诊断/病理分型 → 并发症和肾脏保护 → 治疗与肾替代时机。
- 核心抓手：先按尿检、eGFR和临床综合征定位，再决定是否需要血清学或肾病理分型。
- 最小输出：画出“综合征—尿检—血清学—病理—治疗—肾脏结局”路径。

### 血液系统疾病

- 适用条目：80 个。
- 学习主线：受累细胞谱系 → 生成减少/破坏增加/分布异常 → 血常规与涂片 → 骨髓、免疫表型和遗传学 → 诊断分类与危险分层 → 出血/感染/血栓等并发症 → 病因治疗与支持治疗 → 疗效判定、复发和预后。
- 核心抓手：从细胞谱系和计数异常出发，用形态、免疫和遗传证据逐层完成分类。
- 最小输出：制作“谱系—血象—骨髓—免疫/遗传—分层—治疗”六列表。

### 内分泌轴疾病

- 适用条目：82 个。
- 学习主线：激素轴与反馈关系 → 功能亢进/减退/抵抗 → 原发性与继发性定位 → 病因 → 临床表现 → 基础激素与动态试验 → 影像定位和并发症 → 治疗替代/抑制与长期监测。
- 核心抓手：先画反馈轴，再用上下游激素组合定位病变层级，动态试验只回答特定问题。
- 最小输出：输出一张激素反馈轴和“激素组合—定位—验证试验—治疗”表。

### 代谢与水电解质疾病

- 适用条目：40 个。
- 学习主线：核心生化异常 → 摄入/排出/转移/调节机制 → 病因分类 → 实验室模式 → 临床后果 → 急症识别 → 纠正原则与监测 → 慢性管理和复发预防。
- 核心抓手：用质量守恒和调节激素解释化验模式，并始终区分总量、浓度和分布变化。
- 最小输出：制作“异常值—机制—病因—临床风险—纠正原则—复查指标”表。

### 风湿免疫病

- 适用条目：24 个。
- 学习主线：免疫靶点与机制 → 器官受累谱 → 自身抗体与炎症指标 → 分类/诊断标准 → 疾病活动度与器官损害 → 鉴别感染和肿瘤 → 诱导与维持治疗层级 → 药物安全和长期监测。
- 核心抓手：用器官谱和免疫学证据形成模式识别，同时分开活动度、累积损害和治疗副作用。
- 最小输出：输出“器官谱—抗体—标准—活动度—治疗层级—监测”矩阵。

### 中毒与理化损伤

- 适用条目：50 个。
- 学习主线：暴露史、剂量和时间 → 毒代动力学/损伤机制 → 中毒综合征或器官损伤 → 现场与生命支持 → 毒物检测和监测 → 去污、促进排出与解毒剂 → 并发症与观察终点 → 职业/环境预防。
- 核心抓手：先稳定生命体征，再由暴露史和中毒综合征反推毒物；时间窗决定后续措施。
- 最小输出：画“暴露—时间轴—综合征—生命支持—特异措施—监测终点”急救流程。

## 建议复习节奏

1. 首轮：按 A → B → C 阅读，先完成定义、机制链和诊断入口。
2. 二轮：闭卷完成各框架规定的最小输出，再回原书补缺。
3. 三轮：围绕相似疾病做横向鉴别表，尤其比较相同症状、检查或并发症。
4. 临考：只看自己无法稳定复述的决策节点，不重复抄写完整正文。
