# 双向索引与主动回忆

## 疾病 → 检查

| 疾病主线 | 首轮定位 | 关键分流/确认 | 内科入口 |
| --- | --- | --- | --- |
| 缺铁/巨幼细胞贫血 | CBC、MCV/RDW、涂片、网织红 | 铁代谢或B12/叶酸；追病因 | [[02_红细胞与贫血]] |
| 溶血性贫血 | CBC、网织红、涂片 | 胆红素/LDH/结合珠蛋白/尿线索，再分免疫与非免疫 | [[02_红细胞与贫血]] |
| 再障/MDS | 多系计数、网织红、涂片 | 骨髓形态/活检、流式与遗传学按需 | [[03_白细胞与骨髓增殖]] |
| 白血病/MPN | CBC分类、涂片、脾大/症状 | 骨髓、流式、遗传/分子 | [[03_白细胞与骨髓增殖]] |
| 淋巴瘤 | 淋巴结/脾体检、CBC、影像 | 足量组织病理、免疫表型；分期检查 | [[04_淋巴浆细胞与脾淋巴结]] |
| 浆细胞病 | CBC、肾功能、钙、总蛋白等 | 电泳/免疫固定/轻链、骨髓、骨影像 | [[04_淋巴浆细胞与脾淋巴结]] |
| ITP/凝血因子病/DIC | 出血表型、血小板、PT/APTT/TT/FIB | 涂片、混合/因子检测；DIC看D-二聚体和动态组合 | [[05_出血凝血与血栓]] |

## 检查异常 → 疾病方向

| 异常 | 先排/先确认 | 机制方向 |
| --- | --- | --- |
| 小细胞低色素 | 标本与慢性失血线索 | 缺铁、铁利用障碍、珠蛋白/血红素合成异常 |
| 大细胞 + 中性粒细胞核改变 | 药物、肝病等背景 | 巨幼细胞性改变及其他大细胞原因 |
| 网织红高 + 溶血组合 | 近期输血/出血 | 溶血或失血后的代偿 |
| 原始/幼稚细胞 | 人工涂片复核 | 急性白血病等克隆性疾病，尽快升级取材 |
| 单克隆蛋白 | 确认类型、定量与器官损害 | MGUS/浆细胞或淋巴浆细胞疾病等分层 |
| 血小板低 + PT/APTT近正常 | 假性血小板减少 | 破坏、消耗、生成不足或脾滞留 |
| PT/APTT均延长 + FIB低 + D-二聚体高 | 标本/抗凝药影响 | DIC、严重肝病等综合鉴别，必须结合基础病 |
