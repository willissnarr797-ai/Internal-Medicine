## 代表性因果链

### 心力衰竭

心肌收缩或舒张障碍等 → 有效输出不足和／或充盈压力升高 → 低灌注与肺或体静脉淤血；神经体液代偿短期维持循环，长期可促进重塑与潴留。

**推理题：**为什么水肿和射血分数不足以分别概括心衰严重度及是否存在心衰？

依据入口：[[999_附件文件夹/02_内科学第10版_按章节/020_0302_心力衰竭|心力衰竭]]。这是本章教学综合，疾病亚型仍以原文为准。

### 心律失常

离子电流及组织传导特性改变 → 自律性异常、触发活动或折返等 → 节律或激动顺序异常 → 心电图改变，并可能影响心排血量。

**推理题：**同为心动过速，起源、机制和血流动力学后果为什么要分别判断？

依据入口：[[999_附件文件夹/02_内科学第10版_按章节/021_0303_心律失常|心律失常]]。这是本章教学综合，疾病亚型仍以原文为准。

### 冠状动脉粥样硬化性心脏病

脂质滞留和血管壁炎症促进斑块 → 固定狭窄可限制需氧增加时的供血；斑块破裂或糜烂继发血栓可急剧减少供血 → 缺血，持续严重时发生梗死。

**推理题：**稳定狭窄与急性血栓形成为什么产生不同时间过程？

依据入口：[[999_附件文件夹/02_内科学第10版_按章节/022_0304_动脉粥样硬化和冠状动脉粥样硬化性心脏病|动脉粥样硬化和冠状动脉粥样硬化性心脏病]]。这是本章教学综合，疾病亚型仍以原文为准。

### 高血压

肾钠处理、神经体液调节及血管因素相互作用 → 血容量或外周阻力等改变 → 动脉压升高；长期压力负荷促使心脏和血管重塑及靶器官损伤。

**推理题：**为什么既要理解短期血管张力，也要理解长期肾脏容量调节？

依据入口：[[999_附件文件夹/02_内科学第10版_按章节/023_0305_高血压|高血压]]。这是本章教学综合，疾病亚型仍以原文为准。

### 心脏瓣膜病

瓣口狭窄造成跨瓣压力负荷，关闭不全造成反流及容量负荷 → 心腔代偿性改变 → 代偿失效后发生淤血或输出下降。

**推理题：**同一瓣膜狭窄与关闭不全的上游压力和心腔容量怎样不同？

依据入口：[[999_附件文件夹/02_内科学第10版_按章节/026_0308_心脏瓣膜病|心脏瓣膜病]]。这是本章教学综合，疾病亚型仍以原文为准。

### 心脏压塞

心包内压力升高 → 心脏舒张充盈受限 → 静脉压升高但有效输出下降；积液形成速度和心包顺应性共同决定后果。

**推理题：**为什么积液量相同，快速和缓慢形成时危险程度可以不同？

依据入口：[[999_附件文件夹/02_内科学第10版_按章节/027_0309_心包疾病|心包疾病]]。这是本章教学综合，疾病亚型仍以原文为准。

### 感染性心内膜炎

病原体在心内膜或相关结构形成感染灶及赘生物 → 瓣膜破坏、栓塞和免疫相关损伤 → 心脏与心外多器官表现。

**推理题：**一个瓣膜感染如何解释杂音、远处栓塞和肾脏表现？

依据入口：[[999_附件文件夹/02_内科学第10版_按章节/028_0310_感染性心内膜炎|感染性心内膜炎]]。这是本章教学综合，疾病亚型仍以原文为准。
