## 代表性因果链

### 慢性阻塞性肺疾病

慢性气道炎症与小气道重塑，加上部分患者肺泡壁破坏和弹性回缩力下降 → 呼气气流受限与气体潴留 → 活动时呼吸困难；通气血流失衡可进一步造成低氧。

**推理题：**为什么肺气肿患者肺更容易扩张，却更难把气呼出去？

依据入口：[[999_附件文件夹/02_内科学第10版_按章节/004_0203_慢性阻塞性肺疾病|慢性阻塞性肺疾病]]。这是本章教学综合，疾病亚型仍以原文为准。

### 支气管哮喘

气道炎症、神经调节与气道高反应性相互作用 → 平滑肌收缩、黏液与黏膜水肿 → 可变的气流受限；反复损伤修复可出现重塑。

**推理题：**支气管舒张与抗炎分别切断因果链的哪一段？

依据入口：[[999_附件文件夹/02_内科学第10版_按章节/005_0204_支气管哮喘|支气管哮喘]]。这是本章教学综合，疾病亚型仍以原文为准。

### 支气管扩张症

清除功能受损与反复感染相互促进 → 支气管壁肌肉、弹性和软骨结构破坏 → 持久扩张、分泌物潴留 → 感染再发；血管改变可参与咯血。

**推理题：**气道已经扩大，为什么排痰仍然困难？

依据入口：[[999_附件文件夹/02_内科学第10版_按章节/006_0205_支气管扩张症|支气管扩张症]]。这是本章教学综合，疾病亚型仍以原文为准。

### 肺炎

病原侵入与宿主炎症反应 → 肺泡渗出或肺间质损伤 → 部分区域通气降低但仍有灌注 → 低氧；炎症介质参与发热和全身症状。

**推理题：**肺泡实变如何同时解释影像改变和气体交换异常？

依据入口：[[999_附件文件夹/02_内科学第10版_按章节/007_0206_肺部感染性疾病|肺部感染性疾病]]。这是本章教学综合，疾病亚型仍以原文为准。

### 肺结核

结核分枝杆菌与宿主细胞免疫相互作用 → 渗出、增生和坏死等不同病变 → 可形成肉芽肿、干酪样坏死或空洞；部位与阶段决定表现。

**推理题：**为什么肉芽肿不能单独证明结核，而同一患者又可有不同形态病变？

依据入口：[[999_附件文件夹/02_内科学第10版_按章节/009_0208_肺结核|肺结核]]。这是本章教学综合，疾病亚型仍以原文为准。

### 间质性肺疾病

肺间质和肺泡单位损伤 → 部分疾病进展为纤维化 → 顺应性下降及弥散障碍 → 限制性通气改变与活动后低氧。

**推理题：**为什么应区分可逆炎症与已经形成的纤维化？

依据入口：[[999_附件文件夹/02_内科学第10版_按章节/011_0210_间质性肺疾病|间质性肺疾病]]。这是本章教学综合，疾病亚型仍以原文为准。

### 肺血栓栓塞症

静脉血栓脱落进入肺循环 → 肺血管床阻塞及血管反应 → 肺血管阻力上升、右室负荷增加，同时气体交换失衡 → 呼吸困难，严重时循环障碍。

**推理题：**为什么肺部血管疾病能同时造成低氧和右心衰竭？

依据入口：[[999_附件文件夹/02_内科学第10版_按章节/012_0211_肺血栓栓塞症|肺血栓栓塞症]]。这是本章教学综合，疾病亚型仍以原文为准。

### 气胸与胸腔积液

胸膜腔进入气体破坏原有压力条件，或液体积聚压迫肺 → 肺有效膨胀受限；张力性气胸还可妨碍静脉回流。

**推理题：**胸腔积液为何还需要追问静水压、通透性、蛋白和淋巴回流？

依据入口：[[999_附件文件夹/02_内科学第10版_按章节/014_0213_胸膜疾病|胸膜疾病]]。这是本章教学综合，疾病亚型仍以原文为准。

### 急性呼吸窘迫综合征

肺泡上皮及毛细血管内皮损伤 → 通透性增加、肺水肿与肺泡萎陷 → 分流增加、顺应性降低 → 低氧和呼吸功增加。

**推理题：**ARDS与心源性肺水肿在启动环节上有何不同？

依据入口：[[999_附件文件夹/02_内科学第10版_按章节/016_0215_急性呼吸窘迫综合征|急性呼吸窘迫综合征]]。这是本章教学综合，疾病亚型仍以原文为准。
