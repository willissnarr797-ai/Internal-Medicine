
如果你的目标是把**生理学、诊断学、内科学**真正串起来，我建议不要只按教材目录记，而是用一套“三层分类”。

最适合长期记忆的主轴是：

> **第一层按“发生部位/电活动来源”分类，第二层按“快还是慢”，第三层用“ECG宽窄+规则性”做临床识别。**

这样最不容易乱。

## 一、第一主轴：按发生部位记

这是最适合建立知识地图的分类。

```text
心律失常
│
├─ ① 窦房结异常
│
├─ ② 心房性心律失常
│
├─ ③ 房室交界区/房室结相关
│
├─ ④ 房室旁路相关
│
├─ ⑤ 心室性心律失常
│
└─ ⑥ 传导障碍
```

具体放进去：

|部位|代表心律失常|
|---|---|
|窦房结|窦性心动过速、窦性心动过缓、窦性停搏、病窦综合征|
|心房|房早、房速、房扑、房颤|
|房室结/交界区|交界性逸搏、AVNRT|
|房室旁路|AVRT、WPW相关心律失常|
|心室|室早、室速、尖端扭转、室扑、室颤|
|传导系统|窦房传导阻滞、AV block、束支阻滞|

这套分类最大的好处是，你看到病名就能马上问：

> **异常电活动从哪里来？**

比如：

```text
房性早搏
→ 心房异位起搏点

AVNRT
→ 房室结附近折返

AVRT
→ 房室结 + 旁路构成折返

室速
→ 心室起源
```

## 二、第二层：分成“快速性”和“缓慢性”

内科学尤其喜欢这样处理。

```text
心律失常
├─ 快速性心律失常
└─ 缓慢性心律失常
```

### 快速性

```text
快速性心律失常
│
├─ 窦性心动过速
├─ 房早 / 房速
├─ 房扑
├─ 房颤
├─ AVNRT
├─ AVRT
├─ 室早
├─ 室速
├─ 室扑
└─ 室颤
```

### 缓慢性

```text
缓慢性心律失常
│
├─ 窦性心动过缓
├─ 窦性停搏
├─ 病窦综合征
├─ 窦房传导阻滞
├─ 房室传导阻滞
└─ 逸搏 / 逸搏心律
```

这里你会发现一个规律：

> **快速性心律失常多是“异常冲动形成/折返”；缓慢性心律失常多是“起搏功能下降/传导失败”。**

这正好连接你之前学的生理机制。

## 三、第三层：诊断学按“QRS宽窄 + 规则性”记

到了心电图和急诊判断，不要再首先想着几十个病名。

看到心动过速，第一反应应该是：

```text
心动过速
↓
QRS窄还是宽？
```

### 窄QRS心动过速

一般提示冲动来自心室以上：

```text
窄QRS
<120 ms
↓
室上性为主
```

再判断：

```text
窄QRS
├─ 规则
│   ├─ 窦速
│   ├─ 房速
│   ├─ AVNRT
│   ├─ AVRT
│   └─ 房扑固定传导
│
└─ 不规则
    ├─ 房颤
    ├─ 房扑变比例传导
    └─ 多源性房速
```

其中最重要的一条：

> **窄QRS + RR绝对不规则 → 首先想到房颤。**

---

### 宽QRS心动过速

```text
QRS ≥120 ms
```

最重要原则：

> **宽QRS规则性心动过速，临床上首先按室速考虑，直到证明不是。**

分类：

```text
宽QRS心动过速
├─ 规则
│   ├─ 室速
│   ├─ SVT伴束支阻滞
│   └─ SVT伴差异性传导
│
└─ 不规则
    ├─ 多形性室速
    ├─ 尖端扭转
    ├─ 房颤伴差异性传导
    └─ 预激综合征伴房颤
```

这是诊断学和急诊最实用的一套。

# 四、第四套分类只用来理解机制

生理学里应该再给每一种心律失常贴一个“机制标签”。

```text
心律失常机制
│
├─ 冲动形成异常
│   ├─ 自律性增强
│   └─ 异常自律性
│
├─ 触发活动
│   ├─ EAD
│   └─ DAD
│
└─ 冲动传导异常
    └─ 折返
```

例如：

|心律失常|主要机制|
|---|---|
|窦速|正常自律性增强|
|部分房速|异常自律性|
|洋地黄相关心律失常|DAD|
|尖端扭转|常涉及EAD|
|AVNRT|折返|
|AVRT|折返|
|房扑|大折返|
|很多室速|折返|

但我**不建议你用“机制分类”作为第一记忆主轴**。

原因很简单：
同一种疾病可能不止一种机制。

比如：

```text
房颤
```

不是简单一句“折返”就能概括。

所以机制分类适合回答：

> 为什么发生？

而不是用来组织全部病名。

# 五、我最推荐你脑中建立这张总图

```text
                         心律失常
                            │
          ┌─────────────────┴─────────────────┐
          │                                   │
       快速性                              缓慢性
          │                                   │
   ┌──────┼──────┐                     ┌──────┴──────┐
   │      │      │                     │             │
 心房   AV结/旁路  心室                起搏异常       传导异常
   │      │      │                     │             │
房速    AVNRT   室早                  窦缓          SA block
房扑    AVRT    室速                  窦停          AV block
房颤            TdP                   病窦
                VF
```

然后每一种病再附加三个标签。

例如房颤：

```text
房颤
├─ 部位：心房
├─ 类型：快速性
├─ ECG：窄QRS、RR绝对不规则
└─ 机制：异常心房电活动 + 多重折返等
```

AVNRT：

```text
AVNRT
├─ 部位：AV结附近
├─ 类型：快速性
├─ ECG：规则窄QRS心动过速
└─ 机制：折返
```

室速：

```text
室速
├─ 部位：心室
├─ 类型：快速性
├─ ECG：通常规则宽QRS心动过速
└─ 机制：常见折返等
```

三度房室传导阻滞：

```text
Ⅲ度AV block
├─ 部位：房室传导系统
├─ 类型：缓慢性
├─ ECG：P与QRS无固定关系
└─ 机制：房室传导完全中断
```

## 最终记忆顺序

你以后学一个心律失常，固定问 **5个问题**：

```text
① 从哪里来？
   窦房结 / 心房 / AV结 / 旁路 / 心室 / 传导系统

② 快还是慢？

③ 规则还是不规则？

④ QRS宽还是窄？

⑤ 为什么发生？
   自律性 / 触发活动 / 折返 / 传导阻滞
```

再进入内科学：

```text
⑥ 危险吗？
⑦ 怎么治疗？
```

也就是完整的：

**部位 → 频率 → ECG → 机制 → 危险性 → 治疗。**

这比单纯按照“房早、室早、房颤、房扑、室速……”挨个背，稳定得多。尤其到后面学习抗心律失常药、电复律、射频消融和起搏器时，这套框架还能继续沿用。
