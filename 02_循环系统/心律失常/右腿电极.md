因为**右腿电极（RL）主要不是用来“看心脏”的，而是用来接地、抑制干扰、稳定基线的**，所以它不参与 I、II、III 导联的主要电位差计算。

标准四肢电极是：

```text
RA = 右臂
LA = 左臂
LL = 左腿
RL = 右腿
```

其中真正构成 Einthoven 三角的是：

```text
          RA
         /  \
        / ❤️ \
       /      \
     LA ------ LL
```

所以：

```text
I   = LA - RA
II  = LL - RA
III = LL - LA
```

右腿 RL 没有出现在这里。

它主要起这个作用：

```text
人体接收到大量50/60 Hz交流电干扰
↓
RL电极帮助建立稳定参考
↓
降低共模噪声
↓
ECG波形更干净
```

现代心电图机里常用的是 **Driven Right Leg（右腿驱动）** 电路，不只是简单“接地”，而是把检测到的共模干扰反相后送回人体，从而进一步减少噪声。

你可以把四个电极理解成：

```text
RA ─┐
LA ─┼─→ 用于观察心脏电活动
LL ─┘

RL ───→ 主要用于抗干扰/稳定系统
```

所以**10个电极产生12导联**时：

- RA、LA、LL → 产生6个肢体导联
    
- V1～V6 → 产生6个胸前导联
    
- RL → 主要负责抗干扰，不单独形成一个导联
    

最值得记的一句话：

> **右腿电极是“辅助测量的”，不是“观察心脏方向的”。**
