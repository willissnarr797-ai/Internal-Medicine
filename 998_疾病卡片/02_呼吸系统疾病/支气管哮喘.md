# 306速记总览

- **一句话定位**：慢性气道炎症和气道高反应性所致的**可变症状 + 可变气流受限**。
- **诊断闭环**：反复喘息/气急/胸闷/咳嗽（夜间或凌晨重）→ 发作性、可缓解 → 客观证实可变气流受限。
- **最易错点**：未闻及哮鸣音不能排除哮喘；危重发作反而可出现“沉默肺”。

# 流行病学

> [!book] [[999_附件文件夹/02_内科学第10版_按章节/005_0204_支气管哮喘#【流行病学】|教材：支气管哮喘 · 【流行病学】]]

- 常见慢性气道疾病；死亡多与长期控制不佳或急性发作处理不及时有关。

# 病因和发病机制

> [!book] [[999_附件文件夹/02_内科学第10版_按章节/005_0204_支气管哮喘#【病因和发病机制】|教材：支气管哮喘 · 【病因和发病机制】]]

- 遗传易感与变应原、感染、污染、药物、运动、肥胖和精神因素相互作用。
- Th2/ILC2—IL-4、IL-5、IL-13—IgE/嗜酸性粒细胞轴驱动 2 型炎症；部分重症为中性粒细胞型。
- 气道慢性炎症 → 气道高反应性 → 可逆性支气管收缩；反复发作可发生气道重塑。

# 病理学

> [!book] [[999_附件文件夹/02_内科学第10版_按章节/005_0204_支气管哮喘#【病理】|教材：支气管哮喘 · 【病理】]]

- 上皮损伤、黏膜水肿、炎症细胞浸润、平滑肌痉挛、杯状细胞增生和黏液分泌增加。
- 长期反复发作可见平滑肌肥大/增生、基底膜增厚、胶原沉积和纤维化，即气道重塑。

# 临床表现+症状学

> [!book] [[999_附件文件夹/02_内科学第10版_按章节/005_0204_支气管哮喘#【临床表现】|教材：支气管哮喘 · 【临床表现】]]

- 发作性伴哮鸣音的呼气性呼吸困难，可伴气促、胸闷或咳嗽；夜间及凌晨加重。
- CVA以咳嗽为唯一或主要症状；胸闷变异性哮喘以胸闷为主。
- 危重信号：不能讲话、意识改变、胸腹矛盾运动、哮鸣音减弱/消失、PaCO2升高。

# 实验室检查+影像学+EKG

> [!book] [[999_附件文件夹/02_内科学第10版_按章节/005_0204_支气管哮喘#【实验室和其他检查】|教材：支气管哮喘 · 【实验室和其他检查】]]

- 舒张试验阳性：吸入支扩剂后 `FEV1增加≥12%且绝对值≥200ml`。
- 激发试验阳性：`FEV1下降≥20%`；适用于非发作期且基础 FEV1 通常≥预计值70%。
- PEF平均每日昼夜变异率 `>10%` 或周变异率 `>20%` 支持可变气流受限。
- 嗜酸细胞、FeNO和特异性IgE用于表型/疗效评估，不能单独确诊。

# 并发症

> [!book] [[999_附件文件夹/02_内科学第10版_按章节/005_0204_支气管哮喘#【并发症】|教材：支气管哮喘 · 【并发症】]]

- 重症发作可并发气胸、纵隔气肿和肺不张。
- 长期反复发作或感染可并发 COPD、支气管扩张和肺源性心脏病。

# 诊断和鉴别诊断+病理评估

> [!book] [[999_附件文件夹/02_内科学第10版_按章节/005_0204_支气管哮喘#【诊断】|教材：支气管哮喘 · 【诊断】]]

- 症状/体征具有波动性，并具备舒张试验、激发试验或 PEF 变异中的任一客观证据，同时排除其他原因。
- 鉴别 COPD、左心衰竭、上气道阻塞和 ABPA；单侧或局限性喘鸣要警惕中央气道病变。
- 过去4周按日间症状、夜间憋醒、缓解药使用和活动受限评估控制水平。

# 治疗

> [!book] [[999_附件文件夹/02_内科学第10版_按章节/005_0204_支气管哮喘#【治疗】|教材：支气管哮喘 · 【治疗】]]

- ICS是长期控制哮喘最有效的药物；LABA不能单用，SABA也不建议单药治疗。
- 优选按需低剂量 ICS-福莫特罗；控制不足时阶梯升级，稳定≥3个月可考虑降级。
- 急性发作：吸入 SABA/ICS-福莫特罗，按严重度联合 SAMA、氧疗和全身激素；出现疲劳、PaCO2升高或意识改变时评估有创通气。
- 始终核对吸入技术、依从性、诱因和共病，再判断是否升级药物。
