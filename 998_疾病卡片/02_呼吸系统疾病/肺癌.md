# 306速记总览

- **一句话定位**：先分 NSCLC 与 SCLC，再用 TNM/局限-广泛期决定手术、放疗和全身治疗。
- **诊断闭环**：高危暴露/警示症状 → CT定位和分期 → 获取组织病理 → NSCLC做驱动基因与PD-L1 → 多学科治疗。
- **最易错点**：PET-CT和肿瘤标志物都不能替代病理确诊。

# 流行病学

> [!book] [[999_附件文件夹/02_内科学第10版_按章节/010_0209_肺癌#【流行病学】|教材：肺癌 · 【流行病学】]]

- 肺癌是癌症相关死亡的主要原因；吸烟是最常见且最重要的危险因素。

# 病因和发病机制

> [!book] [[999_附件文件夹/02_内科学第10版_按章节/010_0209_肺癌#【病因和发病机制】|教材：肺癌 · 【病因和发病机制】]]

- 危险因素：主动/被动吸烟、职业致癌物、空气污染和电离辐射。
- 多阶段基因改变导致生长失控；常见驱动/相关异常包括 EGFR、ALK、ROS1、KRAS、TP53、RB1 等。

# 病理学

> [!book] [[999_附件文件夹/02_内科学第10版_按章节/010_0209_肺癌#【分类】|教材：肺癌 · 【分类】]]

- NSCLC约占85%，主要包括鳞癌、腺癌和大细胞癌；腺癌常周围型、较早血行转移。
- SCLC为低分化神经内分泌肿瘤，中央型多见、早期广泛转移，但对放化疗敏感。
- 中央型多起源于段及以上支气管；周围型发生于段以下支气管。

# 临床表现+症状学

> [!book] [[999_附件文件夹/02_内科学第10版_按章节/010_0209_肺癌#【临床表现】|教材：肺癌 · 【临床表现】]]

- 原发肿瘤：刺激性咳嗽、痰血/咯血、局限性喘鸣、胸痛、阻塞性肺炎。
- 局部侵犯：声音嘶哑、上腔静脉阻塞、Horner综合征、胸/心包积液。
- 远处转移：脑、骨、肝和肾上腺；副肿瘤表现包括 SIADH、异位ACTH、高钙血症及肌无力样综合征。

# 实验室检查+影像学+EKG

> [!book] [[999_附件文件夹/02_内科学第10版_按章节/010_0209_肺癌#【影像学及其他检查】|教材：肺癌 · 【影像学及其他检查】]]

- LDCT用于高危人群筛查；增强CT用于定位、纵隔/淋巴结和分期评估。
- 中央型：肺门肿块、阻塞性肺不张/肺炎；周围型：分叶、毛刺、胸膜牵拉或偏心厚壁空洞。
- 病理取材按部位选择支气管镜、EBUS、经皮穿刺、胸腔镜或转移灶活检。
- NSCLC组织应尽量完成驱动基因和PD-L1检测；肿瘤标志物仅作参考。

# 并发症

> [!book] [[999_附件文件夹/02_内科学第10版_按章节/010_0209_肺癌#【临床表现】|教材：肺癌 · 【临床表现】]]

- 阻塞性肺炎、肺不张、癌性空洞/肺脓肿、恶性胸腔积液和咯血。
- 上腔静脉阻塞、心包压塞、脑/骨转移及副肿瘤综合征。

# 诊断和鉴别诊断+病理评估

> [!book] [[999_附件文件夹/02_内科学第10版_按章节/010_0209_肺癌#【诊断与鉴别诊断】|教材：肺癌 · 【诊断与鉴别诊断】]]

- 疑诊后依次完成：CT定位/分期 → 组织病理 → 分子病理；除高度疑似早期可直接手术外，一般必须取得病理。
- 与结核球、肺炎、肺脓肿和肺隐球菌病鉴别；同一部位反复“肺炎”或抗感染后阴影不吸收要警惕。
- NSCLC用TNM分期；SCLC常分局限期与广泛期。

# 治疗

> [!book] [[999_附件文件夹/02_内科学第10版_按章节/010_0209_肺癌#【治疗】|教材：肺癌 · 【治疗】]]

- 治疗由病理类型、分期、分子分型和PS评分共同决定。
- 早期 NSCLC 首选根治性手术；Ⅱ～Ⅲ期常需围手术期化疗/放疗/靶向或免疫的综合策略。
- 晚期 NSCLC：有可靶向驱动基因优先相应靶向治疗；驱动阴性再按PD-L1等选择免疫±化疗。
- SCLC以含铂联合依托泊苷等全身治疗为基础；局限期强调同步放化疗，广泛期常联合免疫治疗。
