# 306速记总览

- **一句话定位**：气体进入胸膜腔使负压消失；张力性气胸是必须立即减压的呼吸循环急症。
- **诊断闭环**：突发单侧胸痛/气促 + 患侧鼓音、呼吸音减弱 → X线/CT气胸线；危重者先减压再完善影像。
- **最易错点**：继发性气胸即使气量小也可能症状重，处理不能只看肺压缩比例。

# 流行病学

> [!book] [[999_附件文件夹/02_内科学第10版_按章节/014_0213_胸膜疾病#【病因和发病机制】|教材：胸膜疾病 · 【病因和发病机制】]]

- 原发性多见于瘦高吸烟男性青壮年；继发性在我国更常见，常有COPD、结核等基础肺病。

# 病因和发病机制

> [!book] [[999_附件文件夹/02_内科学第10版_按章节/014_0213_胸膜疾病#【病因和发病机制】|教材：胸膜疾病 · 【病因和发病机制】]]

- 原发性多由肺尖胸膜下微小疱/肺大疱破裂；继发性由基础肺病破坏肺结构。
- 胸膜腔负压消失 → 肺萎陷和限制性通气障碍；张力性时气体只进不出并压迫回心血流。

# 病理学

> [!book] [[999_附件文件夹/02_内科学第10版_按章节/014_0213_胸膜疾病#【临床类型】|教材：胸膜疾病 · 【临床类型】]]

- 闭合性：破口闭合，空气不再进入。
- 开放性：空气随呼吸自由进出。
- 张力性：单向活瓣，胸腔压力持续升高，纵隔移位并发生梗阻性循环障碍。

# 临床表现+症状学

> [!book] [[999_附件文件夹/02_内科学第10版_按章节/014_0213_胸膜疾病#【临床表现】|教材：胸膜疾病 · 【临床表现】]]

- 突发单侧尖锐胸痛、呼吸困难和刺激性干咳。
- 大量气胸：患侧胸廓隆起、语颤减弱、叩诊鼓/过清音、呼吸音减弱或消失。
- 张力性危象：严重气促、发绀、冷汗、低血压、意识改变和纵隔移位。

# 实验室检查+影像学+EKG

> [!book] [[999_附件文件夹/02_内科学第10版_按章节/014_0213_胸膜疾病#【影像学检查和其他检查】|教材：胸膜疾病 · 【影像学检查和其他检查】]]

- X线见气胸线，线外透亮且无肺纹理；CT更敏感，适合小量/局限气胸及与肺大疱鉴别。
- 血气常低氧、PaCO2正常或降低；肺功能不用于急性气胸常规诊断。
- 病情危重无法搬动时，可在体征最明显处试验穿刺，抽出气体即支持诊断。

# 并发症

> [!book] [[999_附件文件夹/02_内科学第10版_按章节/014_0213_胸膜疾病#（三）并发症及其处理|教材：胸膜疾病 · （三）并发症及其处理]]

- 脓气胸、血气胸、纵隔气肿和皮下气肿。
- 张力性气胸可导致呼吸衰竭、梗阻性休克和死亡；快速复张可发生复张性肺水肿。

# 诊断和鉴别诊断+病理评估

> [!book] [[999_附件文件夹/02_内科学第10版_按章节/014_0213_胸膜疾病#【诊断与鉴别诊断】|教材：胸膜疾病 · 【诊断与鉴别诊断】]]

- 稳定型需同时满足：呼吸<24次/分、心率60～120次/分、血压正常、室内空气SaO2>90%、可成句说话。
- 与哮喘/COPD急性加重、急性心肌梗死、肺栓塞和肺大疱鉴别。
- 慢性气道病患者突然恶化且支扩/抗感染无效，应立即排查气胸。

# 治疗

> [!book] [[999_附件文件夹/02_内科学第10版_按章节/014_0213_胸膜疾病#【治疗】|教材：胸膜疾病 · 【治疗】]]

- 张力性或开放性气胸：**立即排气减压**，随后胸腔闭式引流。
- 稳定、初发、小量且无明显症状者可严密观察和吸氧；有基础肺病者阈值更低。
- 肺压缩>20%、不稳定、明显气促、交通性/张力性、复发或继发性气胸通常需排气/置管。
- 反复或持续漏气可考虑胸膜固定、胸腔镜肺大疱切除等。
