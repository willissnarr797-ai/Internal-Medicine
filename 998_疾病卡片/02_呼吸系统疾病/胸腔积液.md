# 306速记总览

- **一句话定位**：先确认有无积液，再用Light标准分漏出/渗出，最后按性质追查病因。
- **诊断闭环**：影像确认 → 诊断性胸穿 → Light标准 → 细胞/生化/病原/病理寻找病因。
- **最易错点**：Light三项中任意一项阳性即为渗出液；强利尿后的心衰胸水可出现“假性渗出液”。

# 流行病学

> [!book] [[999_附件文件夹/02_内科学第10版_按章节/014_0213_胸膜疾病#【胸腔积液的发病机制】|教材：胸膜疾病 · 【胸腔积液的发病机制】]]

- 胸腔积液是多种胸部或全身疾病的表现，不应把“胸水”当作最终病因诊断。

# 病因和发病机制

> [!book] [[999_附件文件夹/02_内科学第10版_按章节/014_0213_胸膜疾病#【胸腔积液的发病机制】|教材：胸膜疾病 · 【胸腔积液的发病机制】]]

- 漏出液：静水压升高或胶体渗透压降低，常见心衰、肾病综合征、肝硬化。
- 渗出液：胸膜通透性增加或淋巴回流受阻，常见感染、结核、肿瘤和结缔组织病。
- 损伤可形成血胸、脓胸或乳糜胸。

# 病理学

> [!book] [[999_附件文件夹/02_内科学第10版_按章节/014_0213_胸膜疾病#【胸腔积液循环机制】|教材：胸膜疾病 · 【胸腔积液循环机制】]]

- 胸液主要由壁胸膜滤出并经壁胸膜淋巴管回吸收；产生过快或吸收过慢即形成积液。
- 大量积液压迫肺组织，降低通气并可推动纵隔。

# 临床表现+症状学

> [!book] [[999_附件文件夹/02_内科学第10版_按章节/014_0213_胸膜疾病#【临床表现】|教材：胸膜疾病 · 【临床表现】]]

- 少量可无症状；大量时呼吸困难最常见，可伴胸痛和咳嗽。
- 中大量体征：患侧胸廓饱满、语颤减弱、叩诊浊音、呼吸音减弱/消失，纵隔可向健侧移位。

# 实验室检查+影像学+EKG

> [!book] [[999_附件文件夹/02_内科学第10版_按章节/014_0213_胸膜疾病#【实验室和其他检查】|教材：胸膜疾病 · 【实验室和其他检查】]]

- 超声对少量积液敏感，并可估量和引导安全穿刺；CT有助于判断胸膜、肺和纵隔病因。
- Light渗出标准：胸液/血清蛋白>0.5；胸液/血清LDH>0.6；胸液LDH>血清正常上限2/3，任一满足即渗出。
- 结核性胸水常以淋巴细胞为主、ADA升高；恶性胸水需胸水细胞学或胸膜活检证实恶性细胞。

# 并发症

> [!book] [[999_附件文件夹/02_内科学第10版_按章节/014_0213_胸膜疾病#【治疗】|教材：胸膜疾病 · 【治疗】]]

- 大量积液可导致呼吸困难和纵隔移位。
- 胸腔感染可发展为脓胸、包裹和胸膜增厚；快速大量抽液可发生复张性肺水肿。

# 诊断和鉴别诊断+病理评估

> [!book] [[999_附件文件夹/02_内科学第10版_按章节/014_0213_胸膜疾病#【诊断与鉴别诊断】|教材：胸膜疾病 · 【诊断与鉴别诊断】]]

- 三步法：确定有无 → 漏出/渗出 → 寻找原因。
- 漏出液优先考虑心衰、肾病综合征、肝硬化；渗出液优先考虑肺炎旁、结核和恶性肿瘤。
- 复杂性肺炎旁积液常见pH<7.2、葡萄糖<3.3mmol/L、LDH>1000IU/L，提示需要积极引流评估。

# 治疗

> [!book] [[999_附件文件夹/02_内科学第10版_按章节/014_0213_胸膜疾病#【治疗】|教材：胸膜疾病 · 【治疗】]]

- 病因治疗是根本；漏出液常随原发病纠正而吸收。
- 复杂性肺炎旁积液/脓胸：抗感染 + 胸腔引流 + 营养支持。
- 结核性胸膜炎：规范抗结核并及时排液；首次抽液不超过800ml，以后每次不超过1000ml且不宜过快。
- 恶性积液有症状时排液；肺可复张者置管或胸膜固定，不可复张者优先长期置管。
