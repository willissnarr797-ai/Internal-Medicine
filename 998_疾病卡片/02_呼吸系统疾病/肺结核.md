# 306速记总览

- **一句话定位**：结核分枝杆菌所致慢性传染病；确诊核心是病原学/分子证据，治疗核心是早期、规律、全程、适量、联合。
- **诊断闭环**：结核暴露/中毒症状 + 典型影像 → 痰涂片/培养/核酸 → 判断活动性与耐药 → 标准联合化疗。
- **最易错点**：PPD和IGRA提示感染，不能单独确诊或排除活动性肺结核。

# 流行病学

> [!book] [[999_附件文件夹/02_内科学第10版_按章节/009_0208_肺结核#【流行病学】|教材：肺结核 · 【流行病学】]]

- 传染源、传播途径、易感宿主和感染控制是考试常见组合；活动性肺结核需关注传染性。

# 病因和发病机制

> [!book] [[999_附件文件夹/02_内科学第10版_按章节/009_0208_肺结核#【结核病在人体的发生与发展】|教材：肺结核 · 【结核病在人体的发生与发展】]]

- 结核分枝杆菌经呼吸道传播；细胞免疫和迟发型超敏反应共同决定病灶演变。
- 病灶可吸收、纤维化、钙化，也可干酪坏死、液化形成空洞并支气管播散。

# 病理学

> [!book] [[999_附件文件夹/02_内科学第10版_按章节/009_0208_肺结核#【病理学】|教材：肺结核 · 【病理学】]]

- 基本病变包括渗出、增生和干酪样坏死；典型增生性病变为结核结节。
- 机体免疫力与变态反应强弱决定病变性质、范围和转归。

# 临床表现+症状学

> [!book] [[999_附件文件夹/02_内科学第10版_按章节/009_0208_肺结核#【临床表现】|教材：肺结核 · 【临床表现】]]

- 呼吸道症状：咳嗽、咳痰、咯血、胸痛和呼吸困难。
- 全身中毒症状：午后低热、盗汗、乏力、食欲减退和体重下降；也可症状不典型。

# 实验室检查+影像学+EKG

> [!book] [[999_附件文件夹/02_内科学第10版_按章节/009_0208_肺结核#【肺结核的诊断】|教材：肺结核 · 【肺结核的诊断】]]

- 痰抗酸涂片、分枝杆菌培养和核酸检测是关键；培养及药敏用于耐药评估。
- Xpert MTB/RIF可同时检测MTB复合群和利福平耐药相关信息。
- PPD/IGRA只反映感染相关免疫反应；IGRA不能单独确诊或排除活动性结核。
- 影像多见上肺病变、空洞、卫星灶或支气管播散，但最终需与病原学和临床结合。

# 并发症

> [!book] [[999_附件文件夹/02_内科学第10版_按章节/009_0208_肺结核#【肺结核与相关疾病】|教材：肺结核 · 【肺结核与相关疾病】]]

- 大咯血、咯血窒息、气胸、支气管扩张和肺毁损。
- 可并发结核性胸膜炎/脓胸；长期广泛病变可致慢性呼吸衰竭和肺心病。

# 诊断和鉴别诊断+病理评估

> [!book] [[999_附件文件夹/02_内科学第10版_按章节/009_0208_肺结核#【鉴别诊断】|教材：肺结核 · 【鉴别诊断】]]

- 与细菌性肺炎、肺真菌病、肺癌、肺脓肿、结节病和非结核分枝杆菌病鉴别。
- 结核空洞常伴卫星灶；癌性空洞多偏心、壁厚、内壁不规则且进展快。
- 病原学阴性不能自动排除，需综合影像、临床、支气管镜/病理和治疗前证据。

# 治疗

> [!book] [[999_附件文件夹/02_内科学第10版_按章节/009_0208_肺结核#【结核病的化学治疗】|教材：肺结核 · 【结核病的化学治疗】]]

- 原则口诀：**早期、规律、全程、适量、联合**；强化期快速杀菌，巩固期防复发。
- 初治活动性肺结核常用 `2HRZE/4HR`。
- 高频药物不良反应：H—肝损/周围神经炎；R—肝损、体液橘红；Z—肝损/高尿酸；E—视神经炎；S—耳肾毒性。
- 复治或耐药风险必须做药敏并个体化，不能机械沿用固定复治方案。
