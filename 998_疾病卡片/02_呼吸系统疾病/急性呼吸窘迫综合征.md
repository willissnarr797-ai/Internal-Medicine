# 306速记总览

- **一句话定位**：急性诱因后1周内发生的非心源性双肺浸润和难治性低氧，核心病理是弥漫性肺泡损伤。
- **诊断闭环**：明确诱因 → 1周内急性低氧 → 双肺浸润 → 排除心源性/容量过负荷 → 按P/F分级。
- **最易错点**：ARDS是综合征，不是病因；必须同时寻找并治疗诱因。

# 流行病学

> [!book] [[999_附件文件夹/02_内科学第10版_按章节/016_0215_急性呼吸窘迫综合征#【病因】|教材：急性呼吸窘迫综合征 · 【病因】]]

- 肺炎、脓毒症、误吸、创伤、休克、胰腺炎和输血等是常见诱因。

# 病因和发病机制

> [!book] [[999_附件文件夹/02_内科学第10版_按章节/016_0215_急性呼吸窘迫综合征#【病因】|教材：急性呼吸窘迫综合征 · 【病因】]]

- 肺内直接损伤与肺外间接炎症均可导致肺毛细血管内皮和肺泡上皮损伤。
- 通透性肺水肿、表面活性物质减少、肺泡萎陷 → 肺内分流增大和难治性低氧。

# 病理学

> [!book] [[999_附件文件夹/02_内科学第10版_按章节/016_0215_急性呼吸窘迫综合征#【病理与病理生理】|教材：急性呼吸窘迫综合征 · 【病理与病理生理】]]

- 渗出期：弥漫性肺泡损伤、富蛋白水肿、透明膜和“湿肺”。
- 增生期：Ⅱ型肺泡上皮增生和修复；部分进展至纤维化期。
- 病变不均一、有效通气肺容积小，形成“婴儿肺”，解释肺保护通气策略。

# 临床表现+症状学

> [!book] [[999_附件文件夹/02_内科学第10版_按章节/016_0215_急性呼吸窘迫综合征#【临床表现】|教材：急性呼吸窘迫综合征 · 【临床表现】]]

- 多在原发病72小时内发生，几乎不超过7天。
- 最早常为呼吸增快，继而进行性呼吸困难、发绀、烦躁；常规吸氧难以纠正。

# 实验室检查+影像学+EKG

> [!book] [[999_附件文件夹/02_内科学第10版_按章节/016_0215_急性呼吸窘迫综合征#【辅助检查】|教材：急性呼吸窘迫综合征 · 【辅助检查】]]

- X线/CT见双侧斑片、磨玻璃或实变浸润；超声可见双侧B线/实变。
- 柏林分级（PEEP/CPAP≥5cmH2O）：轻度 `200<P/F≤300`，中度 `100<P/F≤200`，重度 `P/F≤100`。
- 心脏超声用于鉴别心源性肺水肿；早期血气常低氧、低CO2和呼吸性碱中毒。

# 并发症

> [!book] [[999_附件文件夹/02_内科学第10版_按章节/016_0215_急性呼吸窘迫综合征#【治疗】|教材：急性呼吸窘迫综合征 · 【治疗】]]

- 呼吸机相关肺损伤、VAP、气压伤、血栓栓塞和ICU获得性衰弱。
- 晚期肺纤维化、肺动脉高压和持续高碳酸血症。

# 诊断和鉴别诊断+病理评估

> [!book] [[999_附件文件夹/02_内科学第10版_按章节/016_0215_急性呼吸窘迫综合征#【诊断】|教材：急性呼吸窘迫综合征 · 【诊断】]]

- 柏林四要素：1周内；双肺浸润；不能完全由心衰/容量过负荷解释；符合低氧分级。
- 鉴别心源性肺水肿、大面积肺不张、大量胸腔积液和弥漫性肺泡出血。
- 2023新定义扩大了HFNC/无创和资源受限环境的氧合评价，但306答题应按题干所给定义作答。

# 治疗

> [!book] [[999_附件文件夹/02_内科学第10版_按章节/016_0215_急性呼吸窘迫综合征#【治疗】|教材：急性呼吸窘迫综合征 · 【治疗】]]

- 先治疗原发病，同时提供器官支持；氧合目标 `PaO2 55～80mmHg` 或 `SaO2 88%～95%`。
- 肺保护通气：潮气量 `4～8ml/kg理想体重`，平台压 `<30cmH2O`；中重度使用合适较高PEEP。
- 重度ARDS俯卧位每日至少12小时；保证灌注前提下限制性液体管理。
- 常规非COVID-19 ARDS不推荐糖皮质激素；难治性重度病例可评估ECMO。
