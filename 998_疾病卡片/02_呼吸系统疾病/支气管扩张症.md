# 306速记总览

- **一句话定位**：支气管壁结构破坏导致不可逆扩张，形成“感染—炎症—结构破坏—清除障碍”的恶性循环。
- **诊断闭环**：反复咳脓痰/咯血 → HRCT见支气管扩张 → 继续追查病因并做痰培养。
- **最易错点**：大量咯血可来自增生的支气管动脉；也可仅反复咯血而少痰（干性支扩）。

# 流行病学

> [!book] [[999_附件文件夹/02_内科学第10版_按章节/006_0205_支气管扩张症#【流行病学】|教材：支气管扩张症 · 【流行病学】]]

- 异质性明显；反复感染、免疫异常、先天纤毛/结构异常和气道阻塞均可诱发。

# 病因和发病机制

> [!book] [[999_附件文件夹/02_内科学第10版_按章节/006_0205_支气管扩张症#【病因和发病机制】|教材：支气管扩张症 · 【病因和发病机制】]]

- 常见继发原因：细菌/结核/NTM/真菌感染、免疫缺陷、ABPA、纤毛缺陷、气道阻塞和结缔组织病。
- 感染与炎症损伤气道壁，分泌物潴留和廓清障碍促进定植，再次加重感染和结构破坏。

# 病理学

> [!book] [[999_附件文件夹/02_内科学第10版_按章节/006_0205_支气管扩张症#【病理和病理生理】|教材：支气管扩张症 · 【病理和病理生理】]]

- 段或亚段支气管软骨、肌肉和弹性组织被破坏并由纤维组织替代。
- 按形态分柱状、囊状和不规则/串珠状扩张；邻近肺实质可有纤维化、肺气肿或肺不张。

# 临床表现+症状学

> [!book] [[999_附件文件夹/02_内科学第10版_按章节/006_0205_支气管扩张症#【临床表现】|教材：支气管扩张症 · 【临床表现】]]

- 稳定期：持续或反复咳嗽、咳痰/脓痰；痰静置可分层。
- 50%～70%可咯血；呼吸困难提示病变广泛或合并 COPD。
- 急性加重可用 48 小时内 6项症状中≥3项恶化识别：咳嗽、痰量、脓痰、呼吸困难/耐量、乏力、咯血。

# 实验室检查+影像学+EKG

> [!book] [[999_附件文件夹/02_内科学第10版_按章节/006_0205_支气管扩张症#【实验室和其他辅助检查】|教材：支气管扩张症 · 【实验室和其他辅助检查】]]

- HRCT是主要诊断方法：支气管/伴行肺动脉直径比 `>1`，可见双轨征、印戒征、串珠/囊状改变和树芽征。
- 初诊及随访留痰做细菌、真菌和抗酸染色/培养；病因筛查包括免疫球蛋白、IgE/曲霉、免疫和纤毛相关检查。
- 肺功能可呈阻塞性、限制性或混合性障碍；血气判断低氧和CO2潴留。

# 并发症

> [!book] [[999_附件文件夹/02_内科学第10版_按章节/006_0205_支气管扩张症#【临床表现】|教材：支气管扩张症 · 【临床表现】]]

- 大咯血、反复肺部感染、肺脓肿。
- 晚期可出现慢性呼吸衰竭、肺动脉高压、慢性肺心病和右心衰竭。

# 诊断和鉴别诊断+病理评估

> [!book] [[999_附件文件夹/02_内科学第10版_按章节/006_0205_支气管扩张症#【诊断与鉴别诊断】|教材：支气管扩张症 · 【诊断与鉴别诊断】]]

- 反复咳脓痰/咯血病史 + HRCT特征即可明确诊断；随后必须评估病因和严重度。
- 与慢支、肺脓肿、肺结核、先天性肺囊肿、弥漫性泛细支气管炎和肺癌鉴别。
- “急起高热+大量脓臭痰+单个液平空洞”更支持肺脓肿；“上肺结核中毒症状+抗酸证据”更支持肺结核。

# 治疗

> [!book] [[999_附件文件夹/02_内科学第10版_按章节/006_0205_支气管扩张症#【治疗】|教材：支气管扩张症 · 【治疗】]]

- 核心是治疗基础病、控制感染和清除气道分泌物；急性加重在取痰培养后尽早经验性抗感染。
- 有铜绿假单胞菌高危因素时选择抗假单胞菌方案；长期大环内酯需先评估QT、听力和肝肾功能。
- 体位引流、拍背、雾化盐水和黏液溶解剂促进排痰。
- 大咯血内科治疗无效可行支气管动脉栓塞；局限病变反复发作可考虑手术。
