# 306速记总览

- **一句话定位**：医院外获得的感染性肺实质炎症；临床表现必须与新发影像浸润相结合。
- **诊断闭环**：社区发病 + 呼吸道/全身炎症表现 + 新发肺部浸润影 → 排除非感染性浸润 → 严重度分层 → 经验性治疗并取病原学。
- **最易错点**：仅发热咳嗽而没有肺实质浸润，不能仅凭症状诊断肺炎。

# 流行病学

> [!book] [[999_附件文件夹/02_内科学第10版_按章节/007_0206_肺部感染性疾病#【流行病学】|教材：肺部感染性疾病 · 【流行病学】]]

- 高龄、吸烟、慢性心肺疾病、糖尿病、肿瘤和免疫低下增加发病与死亡风险。

# 病因和发病机制

> [!book] [[999_附件文件夹/02_内科学第10版_按章节/007_0206_肺部感染性疾病#【病因、发病机制和病理】|教材：肺部感染性疾病 · 【病因、发病机制和病理】]]

- 病原体常经空气吸入、血行播散、邻近蔓延或上呼吸道定植菌误吸进入下呼吸道。
- 是否发病取决于病原体数量/毒力与宿主局部、全身防御能力。
- 常见病原包括肺炎链球菌、支原体、衣原体、流感嗜血杆菌及呼吸道病毒。

# 病理学

> [!book] [[999_附件文件夹/02_内科学第10版_按章节/007_0206_肺部感染性疾病#【病因、发病机制和病理】|教材：肺部感染性疾病 · 【病因、发病机制和病理】]]

- 肺泡毛细血管充血、水肿，肺泡内纤维蛋白渗出和炎细胞浸润。
- 按解剖可分大叶性、小叶性和间质性肺炎；多数治愈后结构与功能可恢复。

# 临床表现+症状学

> [!book] [[999_附件文件夹/02_内科学第10版_按章节/007_0206_肺部感染性疾病#【临床表现】|教材：肺部感染性疾病 · 【临床表现】]]

- 新近咳嗽、咳痰或原有症状加重并出现脓痰，可伴发热、胸痛、呼吸困难或咯血。
- 肺实变体征：浊音、语颤增强、支气管呼吸音；也可仅闻及湿啰音。
- 重症警报：呼吸频率增快、低氧、意识障碍、低血压或多肺叶浸润。

# 实验室检查+影像学+EKG

> [!book] [[999_附件文件夹/02_内科学第10版_按章节/007_0206_肺部感染性疾病#【诊断与鉴别诊断】|教材：肺部感染性疾病 · 【诊断与鉴别诊断】]]

- 影像显示新发片状/斑片状浸润或间质性改变，是诊断闭环的关键。
- CURB-65：意识障碍、尿素氮>7mmol/L、呼吸≥30次/分、收缩压<90或舒张压≤60mmHg、年龄≥65岁。
- 评分0～1分原则上门诊；2分住院或严密随访；3～5分住院，并结合基础病和依从性综合判断。
- 尽量在抗菌药前留取合格痰标本；重症、免疫抑制或经验治疗无效者更应积极明确病原。

# 并发症

> [!book] [[999_附件文件夹/02_内科学第10版_按章节/007_0206_肺部感染性疾病#【治疗】|教材：肺部感染性疾病 · 【治疗】]]

- 呼吸衰竭、感染性休克和多器官功能障碍。
- 肺脓肿、肺炎旁胸腔积液/脓胸；重症可诱发 ARDS。

# 诊断和鉴别诊断+病理评估

> [!book] [[999_附件文件夹/02_内科学第10版_按章节/007_0206_肺部感染性疾病#【诊断与鉴别诊断】|教材：肺部感染性疾病 · 【诊断与鉴别诊断】]]

- 临床诊断：社区发病 + 新发影像浸润 + 咳嗽咳痰/发热/实变体征/白细胞异常中的至少一项，并排除其他病因。
- 鉴别急性支气管炎（无肺实质浸润）、结核、肺癌、肺栓塞、肺水肿和非感染性间质病。
- 同一部位肺炎反复或抗菌治疗后阴影不吸收，要警惕阻塞性肺癌。

# 治疗

> [!book] [[999_附件文件夹/02_内科学第10版_按章节/007_0206_肺部感染性疾病#【治疗】|教材：肺部感染性疾病 · 【治疗】]]

- 先按获得环境、年龄、基础病、误吸风险和严重度经验性抗菌，再根据培养/药敏降阶梯或调整。
- 无基础病青壮年常选青霉素类或一代头孢；有基础病/住院者可选呼吸喹诺酮、二三代头孢或β-内酰胺/酶抑制剂等。
- 重症 CAP 常用β-内酰胺类联合大环内酯或呼吸喹诺酮，并同步进行氧合、循环和器官支持。
- 疗效评估不仅看体温，还要看呼吸、循环、意识、氧合及影像变化。
