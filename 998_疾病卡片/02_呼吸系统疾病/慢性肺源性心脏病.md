# 306速记总览

- **一句话定位**：慢性胸肺/肺血管病 → 肺血管阻力和肺动脉压升高 → 右室结构或功能改变。
- **诊断闭环**：慢性肺病基础 → 肺动脉高压证据 → 右室肥厚/扩大或右衰 → 排除原发左心/瓣膜/心肌病。
- **最易错点**：失代偿期先控制感染、改善通气和纠正缺氧；利尿剂和洋地黄不是一上来常规大剂量使用。

# 流行病学

> [!book] [[999_附件文件夹/02_内科学第10版_按章节/013_0212_肺动脉高压#【流行病学】|教材：肺动脉高压 · 【流行病学】]]

- 患病率随年龄增加，北方和农村较高；冬春季及气候变化时易急性加重。

# 病因和发病机制

> [!book] [[999_附件文件夹/02_内科学第10版_按章节/013_0212_肺动脉高压#【病因】|教材：肺动脉高压 · 【病因】]]

- COPD占慢性肺心病病因约80%～90%；其他有间质病、哮喘、支扩、结核、胸廓和肺血管病。
- 缺氧是形成肺动脉高压最重要因素；还包括高碳酸/酸中毒、肺血管重塑、血管床减少和血黏度增高。

# 病理学

> [!book] [[999_附件文件夹/02_内科学第10版_按章节/013_0212_肺动脉高压#【发病机制和病理生理改变】|教材：肺动脉高压 · 【发病机制和病理生理改变】]]

- 肺循环阻力增加 → 肺动脉高压 → 右室肥厚代偿 → 超过代偿后右室扩大和右心衰竭。
- 缺氧和高碳酸还可造成脑、肝、肾、胃肠和血液系统损害。

# 临床表现+症状学

> [!book] [[999_附件文件夹/02_内科学第10版_按章节/013_0212_肺动脉高压#【临床表现】|教材：肺动脉高压 · 【临床表现】]]

- 代偿期：咳嗽咳痰、气促，P2>A2、剑突下搏动增强，伴原发肺病体征。
- 失代偿期同时出现呼吸衰竭和右心衰竭：发绀/肺性脑病 + 颈静脉怒张、肝大压痛、下肢水肿。

# 实验室检查+影像学+EKG

> [!book] [[999_附件文件夹/02_内科学第10版_按章节/013_0212_肺动脉高压#【辅助检查】|教材：肺动脉高压 · 【辅助检查】]]

- X线见肺动脉高压和右心增大；超声评估右室和肺动脉压力。
- ECG常见电轴右偏、V1 R/S≥1、重度顺钟向转位和肺型P波。
- 血气可见低氧和/或高碳酸；红细胞增多、血黏度升高提示慢性缺氧。

# 并发症

> [!book] [[999_附件文件夹/02_内科学第10版_按章节/013_0212_肺动脉高压#【治疗】|教材：肺动脉高压 · 【治疗】]]

- 肺性脑病、酸碱/电解质紊乱、心律失常、休克、消化道出血、DIC和DVT。

# 诊断和鉴别诊断+病理评估

> [!book] [[999_附件文件夹/02_内科学第10版_按章节/013_0212_肺动脉高压#【诊断】|教材：肺动脉高压 · 【诊断】]]

- 慢性胸肺病史 + 肺动脉高压 + 右室增大/肥厚或右心衰竭证据。
- 与冠心病、风湿性心脏病和原发性心肌病鉴别，重点比较左心/瓣膜证据与慢性肺病背景。
- 急性大面积PTE导致的是急性肺心病，应与慢性肺心病区分。

# 治疗

> [!book] [[999_附件文件夹/02_内科学第10版_按章节/013_0212_肺动脉高压#【治疗】|教材：肺动脉高压 · 【治疗】]]

- 代偿期：治疗基础肺病、预防感染、康复、营养，必要时长期氧疗/家庭无创通气。
- 失代偿期优先：控制感染、通畅气道、改善通气、纠正缺氧/CO2潴留。
- 右衰在上述处理后常可改善；仍明显时小剂量、短疗程、温和利尿并防低钾低氯和痰黏。
- 洋地黄仅限特定指征且小剂量使用；COPD/间质病相关肺心病不常规用肺血管扩张药。
