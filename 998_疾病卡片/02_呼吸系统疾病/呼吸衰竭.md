# 306速记总览

- **一句话定位**：海平面静息呼吸空气时 `PaO2<60mmHg` 和/或 `PaCO2>50mmHg`。
- **诊断闭环**：血气确认并分I/II型 → 判断急慢性和酸碱代偿 → 结合影像/肺功能定位病因 → 呼吸支持+对因。
- **最易错点**：I型是低氧、PaCO2正常/低；II型的本质是肺泡通气不足导致高碳酸。

# 流行病学

> [!book] [[999_附件文件夹/02_内科学第10版_按章节/017_0216_呼吸衰竭与呼吸支持技术#【分类】|教材：呼吸衰竭与呼吸支持技术 · 【分类】]]

- 呼吸衰竭是多种心肺、神经肌肉和胸廓疾病的共同终末综合征，不能脱离病因单独处理。

# 病因和发病机制

> [!book] [[999_附件文件夹/02_内科学第10版_按章节/017_0216_呼吸衰竭与呼吸支持技术#【病理生理机制】|教材：呼吸衰竭与呼吸支持技术 · 【病理生理机制】]]

- I型常由V/Q失调、真性分流或弥散障碍导致；常见于肺炎、ARDS、PTE和间质病。
- II型主要由肺泡通气不足导致；常见于COPD、重症哮喘、气道阻塞、神经肌肉病和胸廓障碍。
- 慢性基础上感染、痉挛或气胸可引起慢性呼吸衰竭急性加重。

# 病理学

> [!book] [[999_附件文件夹/02_内科学第10版_按章节/017_0216_呼吸衰竭与呼吸支持技术#【病理生理机制】|教材：呼吸衰竭与呼吸支持技术 · 【病理生理机制】]]

- V/Q降低形成类分流，V/Q升高形成无效腔；真性分流对提高吸氧浓度反应差。
- 弥散障碍通常先影响O2；CO2弥散更快，早期不一定潴留。
- 高碳酸的关键是肺泡通气量不足，而非单纯CO2生成增加。

# 临床表现+症状学

> [!book] [[999_附件文件夹/02_内科学第10版_按章节/017_0216_呼吸衰竭与呼吸支持技术#【临床表现】|教材：呼吸衰竭与呼吸支持技术 · 【临床表现】]]

- 呼吸困难是最早症状；可见发绀、心动过速和多器官功能障碍。
- 急性低氧可致躁动、昏迷、抽搐；CO2潴留可见嗜睡、扑翼样震颤甚至呼吸停止。
- 慢性高碳酸常先兴奋后抑制、昼夜颠倒；慎用镇静催眠药。

# 实验室检查+影像学+EKG

> [!book] [[999_附件文件夹/02_内科学第10版_按章节/017_0216_呼吸衰竭与呼吸支持技术#【诊断】|教材：呼吸衰竭与呼吸支持技术 · 【诊断】]]

- 动脉血气是诊断与分型核心：I型 `PaO2<60` 且PaCO2正常/低；II型 `PaCO2>50`，可伴低氧。
- pH判断代偿：PaCO2升高且pH<7.35提示失代偿性呼吸性酸中毒。
- 胸部影像、肺功能、支气管镜和心脏评估用于定位原发病。

# 并发症

> [!book] [[999_附件文件夹/02_内科学第10版_按章节/017_0216_呼吸衰竭与呼吸支持技术#【治疗】|教材：呼吸衰竭与呼吸支持技术 · 【治疗】]]

- 肺性脑病、肺动脉高压/肺心病、心律失常。
- 肾功能不全、消化道出血、酸碱/电解质紊乱和DIC。

# 诊断和鉴别诊断+病理评估

> [!book] [[999_附件文件夹/02_内科学第10版_按章节/017_0216_呼吸衰竭与呼吸支持技术#【诊断】|教材：呼吸衰竭与呼吸支持技术 · 【诊断】]]

- 先看血气类型，再看影像：I型且影像近正常应考虑肺血管/右心病变；影像异常再分肺源性和心源性。
- II型优先寻找阻塞性/限制性通气障碍、神经肌肉抑制、气道阻塞及无效腔增加。
- 解释血气时必须结合吸氧浓度、海拔和既往平素PaCO2。

# 治疗

> [!book] [[999_附件文件夹/02_内科学第10版_按章节/017_0216_呼吸衰竭与呼吸支持技术#【治疗】|教材：呼吸衰竭与呼吸支持技术 · 【治疗】]]

- 总原则：呼吸支持 + 对因治疗 + 并发症处理，并维持循环和内环境稳定。
- 慢性CO2潴留者采用控制性低浓度氧疗，避免仅追求高血氧而加重高碳酸。
- 按意识、气道保护、分泌物、酸中毒和呼吸功选择无创或有创机械通气。
- 慢性呼衰急性加重常需抗感染、通畅气道和谨慎纠正酸碱；PaCO2目标应接近平素水平而非强行正常化。
