# 306速记总览

- **一句话定位**：感染导致肺组织坏死和脓腔形成，典型为高热、咳嗽、大量脓臭痰及含气液平面的空洞。
- **诊断闭环**：误吸/感染危险因素 → 急性高热、脓臭痰 → 影像液平空洞 → 需氧+厌氧培养并排除癌/结核。
- **最易错点**：吸入性多为厌氧混合感染；血源性多发、周边分布，常见金葡菌等。

# 流行病学

> [!book] [[999_附件文件夹/02_内科学第10版_按章节/008_0207_肺脓肿#【病因和发病机制】|教材：肺脓肿 · 【病因和发病机制】]]

- 可见于任何年龄，青壮年男性较多；病原体以厌氧菌和兼性厌氧菌为主。

# 病因和发病机制

> [!book] [[999_附件文件夹/02_内科学第10版_按章节/008_0207_肺脓肿#【病因和发病机制】|教材：肺脓肿 · 【病因和发病机制】]]

- 吸入性：误吸口咽分泌物，常累及右肺；仰卧时好发上叶后段或下叶背段。
- 继发性：坏死性肺炎、气道阻塞、支扩、结核空洞或邻近脓肿蔓延。
- 血源性：感染性菌栓播散，常形成双肺多发胸膜下病灶。

# 病理学

> [!book] [[999_附件文件夹/02_内科学第10版_按章节/008_0207_肺脓肿#【病理】|教材：肺脓肿 · 【病理】]]

- 细支气管阻塞和小血管炎性栓塞 → 肺组织坏死液化 → 破入支气管后形成气液平面。
- 病程迁延3个月以上、脓腔壁纤维化增厚者为慢性肺脓肿。

# 临床表现+症状学

> [!book] [[999_附件文件夹/02_内科学第10版_按章节/008_0207_肺脓肿#【临床表现】|教材：肺脓肿 · 【临床表现】]]

- 畏寒高热、咳嗽；1～2周后可突然咳出大量脓臭痰，排痰后体温和中毒症状下降。
- 可有咯血；破入胸膜腔可出现突发胸痛、气急和脓气胸。

# 实验室检查+影像学+EKG

> [!book] [[999_附件文件夹/02_内科学第10版_按章节/008_0207_肺脓肿#【实验室和其他检查】|教材：肺脓肿 · 【实验室和其他检查】]]

- 白细胞和中性粒细胞明显升高；在抗菌药前留痰、血或胸水做需氧及厌氧培养。
- X线/CT见炎性实变内圆形空洞和气液平面；CT更利于定位、鉴别肿瘤和发现小脓肿。
- 支气管镜用于查明阻塞、取材并促进脓液引流。

# 并发症

> [!book] [[999_附件文件夹/02_内科学第10版_按章节/008_0207_肺脓肿#【病理】|教材：肺脓肿 · 【病理】]]

- 脓胸、脓气胸、支气管胸膜瘘。
- 大咯血、感染播散；迁延可形成慢性脓肿和支气管扩张。

# 诊断和鉴别诊断+病理评估

> [!book] [[999_附件文件夹/02_内科学第10版_按章节/008_0207_肺脓肿#【诊断与鉴别诊断】|教材：肺脓肿 · 【诊断与鉴别诊断】]]

- 误吸危险因素 + 高热、大量脓臭痰 + 炎性阴影内脓腔/液平面可诊断。
- 肺结核空洞多病程慢、上肺、结核中毒症状且一般无液平；癌性空洞偏心、壁厚、内壁凹凸。
- 单纯肺炎无典型脓腔；肺囊肿/肺大疱继发感染的周围炎症和中毒症状通常较轻。

# 治疗

> [!book] [[999_附件文件夹/02_内科学第10版_按章节/008_0207_肺脓肿#【治疗】|教材：肺脓肿 · 【治疗】]]

- 两大核心：有效抗感染 + 充分脓液引流。
- 吸入性需覆盖厌氧菌；按培养/药敏调整，疗程通常6～8周，直到症状及脓腔炎症基本消失。
- 体位引流、化痰和支气管镜吸引促进排脓。
- 内科治疗>3个月仍不缩小、脓腔>5cm、瘘/脓胸、大咯血或疑肿瘤阻塞时考虑外科。
