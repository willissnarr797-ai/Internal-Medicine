# 306速记总览

- **一句话定位**：慢性呼吸症状 + 持续、进行性气流受限；确诊关键是吸入支气管扩张剂后 `FEV1/FVC < 70%`。
- **诊断闭环**：吸烟/粉尘等暴露 → 慢性咳嗽咳痰、进行性活动后气促 → 肺功能证实持续气流受限 → 排除其他特征性气流受限疾病。
- **最易错点**：只有慢性支气管炎或肺气肿、但没有持续气流受限，不能诊断 COPD。

# 流行病学

> [!book] [[999_附件文件夹/02_内科学第10版_按章节/004_0203_慢性阻塞性肺疾病#【病因】|教材：慢性阻塞性肺疾病 · 【病因】]]

- 常见且疾病负担重；患病率随年龄和烟草暴露增加。
- 在我国是慢性呼吸衰竭和慢性肺源性心脏病最常见的病因。

# 病因和发病机制

> [!book] [[999_附件文件夹/02_内科学第10版_按章节/004_0203_慢性阻塞性肺疾病#【发病机制】|教材：慢性阻塞性肺疾病 · 【发病机制】]]

- 环境暴露与宿主因素长期相互作用；吸烟是最重要的可干预危险因素。
- 炎症、蛋白酶-抗蛋白酶失衡和氧化应激共同损伤小气道与肺实质。
- 小气道狭窄/黏液栓 + 肺气肿导致弹性回缩力下降和呼气期小气道塌陷，形成持续气流受限。

# 病理学

> [!book] [[999_附件文件夹/02_内科学第10版_按章节/004_0203_慢性阻塞性肺疾病#【病理】|教材：慢性阻塞性肺疾病 · 【病理】]]

- 核心病变是慢性支气管炎与肺气肿；肺泡壁破坏、气腔扩大且无明显纤维化。
- 肺气肿以小叶中央型多见；也可见全小叶型或混合型。
- 通气/血流比例失调、弥散面积减少，晚期导致低氧血症、高碳酸血症和呼吸衰竭。

# 临床表现+症状学

> [!book] [[999_附件文件夹/02_内科学第10版_按章节/004_0203_慢性阻塞性肺疾病#【临床表现】|教材：慢性阻塞性肺疾病 · 【临床表现】]]

- 慢性咳嗽、咳痰；**进行性活动后气短是标志性症状**。
- 急性加重常表现为 14 天内呼吸困难和/或咳嗽、咳痰增加，可伴呼吸急促、心动过速。
- 典型体征：桶状胸、语颤减弱、过清音、呼吸音减弱和呼气相延长。

# 实验室检查+影像学+EKG

> [!book] [[999_附件文件夹/02_内科学第10版_按章节/004_0203_慢性阻塞性肺疾病#【实验室和其他辅助检查】|教材：慢性阻塞性肺疾病 · 【实验室和其他辅助检查】]]

- 肺功能是诊断必备检查：支气管扩张剂后 `FEV1/FVC < 70%`。
- GOLD 1～4 级按 `FEV1%预计值` 分为 `≥80%`、`50%～<80%`、`30%～<50%`、`<30%`。
- 稳定期同时评估 mMRC/CAT 与上一年急性加重；血气用于判断低氧、高碳酸和酸碱失衡。
- X线/CT主要用于显示肺气肿、并发症并排除其他疾病，不能替代肺功能确诊。

# 并发症

> [!book] [[999_附件文件夹/02_内科学第10版_按章节/004_0203_慢性阻塞性肺疾病#【并发症】|教材：慢性阻塞性肺疾病 · 【并发症】]]

- 慢性呼吸衰竭。
- 自发性气胸：呼吸困难突然加重、患侧鼓音、呼吸音减弱或消失。
- 慢性肺源性心脏病：低氧性肺血管收缩和血管床减少 → 肺动脉高压 → 右心衰竭。

# 诊断和鉴别诊断+病理评估

> [!book] [[999_附件文件夹/02_内科学第10版_按章节/004_0203_慢性阻塞性肺疾病#【诊断与稳定期病情严重程度评估】|教材：慢性阻塞性肺疾病 · 【诊断与稳定期病情严重程度评估】]]

- 确诊必须同时抓住危险因素/症状和肺功能证据，并排除支扩、结核后纤维化、严重间质病等。
- 与哮喘鉴别：COPD多中年后起病、长期吸烟、缓慢进展且气流受限持续；哮喘多有变应背景、波动性和显著可逆性。
- 上一年 `≥2次` 中度加重或 `≥1次` 因加重住院，提示未来急性加重高风险。

# 治疗

> [!book] [[999_附件文件夹/02_内科学第10版_按章节/004_0203_慢性阻塞性肺疾病#【治疗】|教材：慢性阻塞性肺疾病 · 【治疗】]]

- 稳定期：戒烟最能减慢肺功能损害；支气管扩张剂是控制症状的核心，按症状和加重风险选择 LABA/LAMA。
- ICS不是所有 COPD 的基础药：频繁加重、血嗜酸细胞较高或有哮喘特征时考虑；反复肺炎、分枝杆菌感染或 EOS<100/μl 时慎用。
- 长期家庭氧疗：`PaO2≤55mmHg` 或 `SaO2≤88%`；若伴肺动脉高压/右衰/红细胞增多，阈值放宽至 `PaO2 55～60mmHg`。
- 急性加重：短效支扩 + 控制性低浓度氧疗 + 有抗菌指征时抗生素 + 短疗程全身激素；严重呼吸衰竭评估机械通气。
