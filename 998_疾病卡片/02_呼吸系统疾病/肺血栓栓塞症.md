# 306速记总览

- **一句话定位**：DVT血栓脱落阻塞肺动脉，诊断按“疑诊—确诊—求因”，治疗先看血流动力学。
- **诊断闭环**：危险因素/症状 → 临床可能性 + D-二聚体 → CTPA/VQ确诊 → 风险分层 → 抗凝±再灌注。
- **最易错点**：D-二聚体阴性主要用于低临床可能性排除；阳性不能确诊。

# 流行病学

> [!book] [[999_附件文件夹/02_内科学第10版_按章节/012_0211_肺血栓栓塞症#【流行病学】|教材：肺血栓栓塞症 · 【流行病学】]]

- VTE风险随年龄增加；PTE致死、致残风险高，但临床表现缺乏特异性。

# 病因和发病机制

> [!book] [[999_附件文件夹/02_内科学第10版_按章节/012_0211_肺血栓栓塞症#【危险因素】|教材：肺血栓栓塞症 · 【危险因素】]]

- Virchow三要素：静脉血流淤滞、血管内皮损伤、血液高凝。
- 常见获得性危险因素：制动/手术/创伤、肿瘤、妊娠/口服避孕药、既往VTE和急性内科住院。
- 多数栓子来自下肢深静脉；机械阻塞和神经体液作用使肺血管阻力、右心后负荷升高。

# 病理学

> [!book] [[999_附件文件夹/02_内科学第10版_按章节/012_0211_肺血栓栓塞症#【病理和病理生理】|教材：肺血栓栓塞症 · 【病理和病理生理】]]

- 肺血管阻塞 → 右室扩张/缺血 → 左室充盈和心排量下降，严重时梗阻性休克。
- 灌注减少造成无效腔增加和V/Q失调；远端栓塞可致肺梗死、咯血和胸腔积液。

# 临床表现+症状学

> [!book] [[999_附件文件夹/02_内科学第10版_按章节/012_0211_肺血栓栓塞症#【临床表现】|教材：肺血栓栓塞症 · 【临床表现】]]

- 最常见为突发或不明原因呼吸困难；可有胸痛、咯血、晕厥、惊恐和干咳。
- “呼吸困难+胸痛+咯血”三联征仅约20%，缺少三联征不能排除。
- 注意不对称下肢肿胀/疼痛和右心负荷体征；重症可低血压、休克或猝死。

# 实验室检查+影像学+EKG

> [!book] [[999_附件文件夹/02_内科学第10版_按章节/012_0211_肺血栓栓塞症#【诊断】|教材：肺血栓栓塞症 · 【诊断】]]

- 低临床可能性且D-二聚体<500μg/L可基本排除；>50岁可用年龄×10μg/L校正阈值。
- CTPA是首选确诊检查，直接征象为肺动脉充盈缺损；V/Q不匹配适用于造影剂禁忌等情况。
- 血气常低氧、低碳酸；ECG可见窦速、V1～V4 T波改变或SⅠQⅢTⅢ，但均非特异。
- 超声/CT右室扩张及肌钙蛋白、BNP升高用于风险分层。

# 并发症

> [!book] [[999_附件文件夹/02_内科学第10版_按章节/012_0211_肺血栓栓塞症#【PTE 的临床分型】|教材：肺血栓栓塞症 · 【PTE 的临床分型】]]

- 急性右心衰竭、梗阻性休克、猝死和矛盾性栓塞。
- 血栓未完全溶解或反复栓塞可发展为 CTEPH。

# 诊断和鉴别诊断+病理评估

> [!book] [[999_附件文件夹/02_内科学第10版_按章节/012_0211_肺血栓栓塞症#【诊断】|教材：肺血栓栓塞症 · 【诊断】]]

- 疑诊：危险因素+临床表现并进行可能性评估；确诊：CTPA/VQ等；求因：查DVT和易栓/肿瘤因素。
- 高危：血流动力学不稳定；中危：稳定但有右室功能不全和/或心脏标志物升高；低危：两者均无。
- 鉴别 ACS、主动脉夹层、肺炎、哮喘、气胸和其他原因休克；PTE休克属于梗阻性休克。

# 治疗

> [!book] [[999_附件文件夹/02_内科学第10版_按章节/012_0211_肺血栓栓塞症#【治疗方案及原则】|教材：肺血栓栓塞症 · 【治疗方案及原则】]]

- 抗凝是基础治疗，确诊后尽早开始；无特殊情况至少抗凝3个月。
- 高危PTE且无禁忌应尽早溶栓；中危不常规系统溶栓，低危不溶栓。
- 高危/恶化且溶栓禁忌或失败时评估导管介入或外科取栓。
- 不常规放置下腔静脉滤器；主要用于急性PTE且存在抗凝禁忌等特定情形。
