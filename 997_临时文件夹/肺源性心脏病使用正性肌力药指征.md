可以。这里说的“肺源性心脏病使用正性肌力药”，在内科学考试语境里通常主要指**洋地黄类药物**。之所以要设置这些比较严格的指征，是因为**肺心病右心衰的病理机制和普通左心衰不一样**。

肺心病的核心链条是：

**COPD/慢性肺病 → 缺氧 → 肺血管收缩和重构 → 肺动脉高压 → 右心室后负荷增加 → 右心衰**

也就是说，肺心病心衰的“根”主要在**肺和肺循环阻力过高**，并不一定是心肌本身收缩力不足。因此，单纯增强心肌收缩力往往不是第一选择，首先应该解决**感染、缺氧、气道阻塞、容量负荷**这些问题。

### 1. 感染控制、呼吸功能改善、利尿后，右心功能仍无明显改善

这是最典型的“排除可逆因素后再用”。

肺心病急性加重时，右心衰经常是因为：

**肺部感染 → 缺氧加重 → 肺血管收缩 → 肺动脉压进一步升高 → 右室负荷骤增**

这时如果直接用强心药，相当于只让右心“更用力地泵”，但前面的肺血管阻力还很高，效果有限。

所以先处理：

**抗感染 + 改善通气 + 氧疗 → 降低肺血管阻力**

再适度利尿：

**减少静脉淤血和右心容量负荷**

如果这些都做好了，右心输出量还是低，才说明此时可能确实存在较明显的**心肌收缩功能不足**，这时正性肌力药才更有价值。

可以理解成：

> 先把“路上的阻力”解决掉，再考虑“发动机动力不足”。

---

### 2. 以右心衰竭为主要表现，而无明显感染

这类患者没有明显感染这一强烈诱因，因此右心衰可能更多反映：

**长期肺动脉高压 → 右室肥厚、扩张 → 右室失代偿**

此时问题已经不只是“缺氧导致肺血管暂时收缩”，而是右心本身已经出现比较明显的泵功能下降。

因此正性肌力药更有可能提高：

**右室收缩力 → 每搏输出量↑ → 心排血量↑**

所以属于可以考虑使用的情况。

---

### 3. 合并室上性快速心律失常

这一条很好理解，但要注意这里主要体现的是**洋地黄的另一项作用：减慢房室传导**。

例如某些患者合并：

**房颤伴快速心室率、房扑等室上性快速心律失常**

心率过快会造成两个问题：

**舒张期缩短 → 心室充盈不足 → 心排血量进一步下降**

同时肺心病患者右心已经处于高负荷状态，心率再过快会明显增加心肌耗氧。

洋地黄不仅能增强心肌收缩力，还可以：

**增强迷走神经作用 → 抑制房室结传导 → 降低心室率**

因此这时它同时解决：

**“心率太快” + “心肌收缩力不足”**

所以适应证更明确。

但要注意，临床上具体选择仍要看心律失常类型、血流动力学和患者基础情况，不能理解成“所有室上速都首选洋地黄”。

---

### 4. 合并急性左心衰

这时病理生理已经不再是单纯右心衰。

如果肺心病患者同时出现左心衰：

**左室收缩功能下降 → 心排血量下降 → 肺静脉压升高 → 肺淤血**

正性肌力药可以通过增加左室收缩力，改善心排血量。

所以相比于单纯肺心病右心衰，出现**急性左心衰**后，强心治疗的理由就更充分。

也就是：

**单纯肺心病：主要问题在肺血管阻力 → 强心作用有限**

而

**肺心病 + 左心衰：出现明显泵衰竭 → 正性肌力药更有意义**

---

### 为什么用药前一定要纠正缺氧？

这是这道知识点里最重要的机制之一。

肺心病患者往往同时存在：

**缺氧 + 高碳酸血症 + 酸中毒 + 电解质紊乱**

这些因素会显著增加洋地黄毒性和心律失常风险。

尤其是缺氧状态下，心肌细胞本身就处于电生理不稳定状态：

**缺氧 → ATP生成减少 → 离子泵功能异常 → K⁺、Na⁺、Ca²⁺跨膜分布异常 → 心肌兴奋性升高**

洋地黄本身又是通过抑制 **Na⁺/K⁺-ATP酶** 增强心肌收缩。

于是二者叠加后：

**缺氧导致电稳定性下降 + 洋地黄改变离子转运 → 异位兴奋增加 → 心律失常风险明显升高**

特别容易出现：

**室性早搏、房室传导阻滞、各种快速性心律失常，严重可出现致命性室性心律失常。**

而且肺心病患者常使用利尿剂，还可能出现：

**低钾血症**

低钾会进一步增强洋地黄与 Na⁺/K⁺-ATP酶的结合，使洋地黄毒性更明显。

所以可以把这部分串成一条考试链：

**肺心病 → 缺氧/酸中毒 + 利尿剂导致低钾 → 心肌电稳定性下降 → 洋地黄敏感性↑ → 易发生中毒性心律失常**

因此必须先尽量纠正：

**缺氧、酸中毒、电解质紊乱，尤其低钾。**

你可以最后记一句：

> **肺心病的右心衰首先治“肺”，不是首先治“心”；只有肺部因素处理后仍有泵功能障碍，或同时存在快速室上性心律失常、左心衰时，才更考虑正性肌力药。**

这也是为什么肺心病的治疗顺序往往可以概括为：

**控制感染 → 改善通气和氧合 → 利尿减负荷 → 必要时强心。**
