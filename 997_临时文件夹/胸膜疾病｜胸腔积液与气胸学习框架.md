# 胸膜疾病｜胸腔积液与气胸背诵版

> **总纲：**
> 
> 胸膜疾病主要包括：
> 
> 1. **液体 → 胸腔积液**
>     
> 2. **气体 → 气胸**
>     
> 3. **固体 → 胸膜肿瘤**
>     
> 
> ⭐ 本章重点：**胸腔积液 + 气胸**

---

# 第一节 胸腔积液

## 一、定义

**胸腔积液（pleural effusion）**

> 胸膜腔内液体**产生过快和/或吸收过缓** → 液体异常积聚。

正常胸膜腔：
为潜在腔隙
少量液体起润滑作用
液体处于不断滤出—吸收的动态平衡


---

# 二、胸液正常循环 ⭐

## 1. 核心结构

胸腔液体主要：
壁胸膜产生
壁胸膜淋巴管吸收


原因：
壁胸膜 → 体循环
脏胸膜 → 主要为肺循环
体循环压力 > 肺循环压力


因此：

```text
壁胸膜毛细血管
        ↓ 滤出
      胸膜腔
        ↓
壁胸膜淋巴微孔
        ↓
     淋巴循环
```

---

## 2. 压力关系

### 壁胸膜

液体滤出压力：

```text
毛细血管静水压
+ 胸腔负压
+ 胸液胶体渗透压
- 毛细血管胶体渗透压
```

教材数据：

```text
30 + 5 + 5 - 34
= 6 cmH₂O
```

→ **促进液体进入胸膜腔**

### 脏胸膜

```text
24 + 5 + 5 - 34
= 0 cmH₂O
```

→ 对胸腔液体循环作用较小。

### 一句话记忆

> **胸液主要从壁胸膜滤出，再经壁胸膜淋巴管吸收。**

---

# 三、胸腔积液发病机制 ⭐⭐⭐

## 六大机制

### 1. 毛细血管静水压升高

```text
静水压↑
→ 液体滤出↑
→ 胸腔积液
```

常见：
充血性心力衰竭
缩窄性心包炎
血容量增加
上腔静脉/奇静脉受阻


→ 多为**漏出液**

---

### 2. 毛细血管胶体渗透压降低

核心：

```text
血浆白蛋白↓
→ 血浆胶体渗透压↓
→ 液体回吸收↓
→ 胸腔积液
```

常见：
低蛋白血症
肝硬化
肾病综合征
急性肾小球肾炎
黏液性水肿


→ 多为**漏出液**

---

### 3. 胸膜通透性增加

```text
炎症/肿瘤
→ 毛细血管通透性↑
→ 蛋白质、细胞进入胸腔
→ 胸腔积液
```

常见：
结核
肺炎旁胸腔积液
SLE
类风湿关节炎
恶性肿瘤
肺梗死
膈下感染
急性胰腺炎


→ 多为**渗出液**

---

### 4. 壁胸膜淋巴回流受阻

```text
淋巴引流↓
→ 液体和蛋白不能回流
→ 胸腔积液
```

常见：

- 恶性肿瘤淋巴阻塞
    
- 先天淋巴管异常
    
- 外伤
    

---

### 5. 损伤

如：
主动脉瘤破裂
食管破裂
胸导管破裂


可产生：
血胸
脓胸
乳糜胸


---

### 6. 医源性

如：
药物
放疗
中心静脉置管
消化内镜操作
CABG
腹膜透析等


---

## 发病机制口诀

> **“压高、蛋低、膜漏、淋堵、损伤、医源”**

即：

```text
静水压↑
胶体渗透压↓
胸膜通透性↑
淋巴回流↓
损伤
医源性
```

最常见：

### 特点

随着胸水增加：

```text
胸痛 ↓
胸闷、气促 ↑
```

---

## 2. 体征 ⭐

### 少量积液

可无明显体征，或：
胸膜摩擦感

### 中—大量积液

典型：

```text

```

大量时：

> 气管、纵隔可向**健侧移位**

### 口诀

> **“饱、颤低、叩浊、呼低”**




## 5. 淀粉酶升高

# 九、漏出液 vs 渗出液 ⭐⭐⭐⭐⭐

## Light标准——必背

> **以下任意一项满足 → 渗出液**

|Light标准|渗出液|
|---|--:|
|胸液蛋白 / 血清蛋白|**>0.5**|
|胸液LDH / 血清LDH|**>0.6**|
|胸液LDH|**>血清LDH正常上限的2/3**|

### 口诀

> **“蛋白半、LDH六成、LDH上限三分二”**

即：

```text
蛋白比 >0.5
LDH比 >0.6
LDH >正常上限2/3
```

### 判断原则

```text
满足任意1项 → 渗出液
3项均不满足 → 漏出液
```

# 十、漏出液常见病因

重点：

1. **充血性心力衰竭**
    
2. **肾病综合征**
    
3. **肝硬化**
    

其他：
急性肾小球肾炎

黏液性水肿等


### 特点

心力衰竭
常双侧
右侧较多
强烈利尿后可形成假性渗出液

```text
NT-proBNP >1500 pg/ml
```

#### 肝硬化

> 多为**右侧胸腔积液**

# 十一、渗出液三大常见病因 ⭐⭐⭐⭐⭐

> **肺炎旁胸腔积液 + 结核 + 恶性肿瘤**

---

# 十二、肺炎旁胸腔积液

定义：

由：
肺炎
肺脓肿
支气管扩张


等感染引起的胸腔积液。

---

## 分类

### 1. 单纯性肺炎旁积液

```text
炎症反应
→ 反应性渗出
→ 无明显细菌侵入胸膜腔
```

随肺炎好转可自行吸收。

### 2. 复杂性肺炎旁积液

```text
细菌进入胸膜腔
→ 炎症加重
→ pH↓、糖↓、LDH↑
```

### 3. 脓胸

> 胸腔内形成**脓液**

---

## 三者鉴别 ⭐

|指标|单纯性|复杂性|脓胸|
|---|---|---|---|
|外观|浆液性|混浊|脓性|
|pH|**>7.2**|**<7.2**|明显异常|
|葡萄糖|**>3.3**|**<3.3 mmol/L**|低|
|LDH|**<1000**|**>1000 IU/L**|高|
|培养|阴性|可阳性|可阳性|

### 极简记忆

> **“复杂：酸、低糖、高LDH”**

```text
pH↓
葡萄糖↓
LDH↑
```

# 十六、胸腔积液治疗总原则

> **病因治疗最重要。**

---

## 肺炎旁胸水

### 单纯性

> 抗生素治疗肺炎 → 多可吸收

### 复杂性/脓胸

三原则：

> **控制感染 + 引流胸水 + 营养支持**

抗生素疗程：

> **2～6周**

---

## 结核性胸膜炎

### 治疗目标

1. 控制结核
    
2. 清除胸水
    
3. 减少胸膜粘连、增厚
    
4. 保护肺功能
    

### 抽液

原则：

> **尽快抽液**

首次：

```text
≤800 ml
```

以后每次：

```text
≤1000 ml
```

禁止：

> **抽液过快**

---

### 抽液过快的并发症 ⭐

#### 复张性肺水肿

表现：
剧咳
气促
大量泡沫痰
湿啰音
PaO₂下降


原因：

> 胸腔压力骤降 → 肺快速复张

---

### 胸膜反应

抽液时出现：
头晕
面色苍白
出汗
心悸
四肢发凉


处理：

> **立即停止抽液 + 平卧**

必要时：

```text
0.1% 肾上腺素 0.5 ml 皮下注射
```

# 第二节 气胸

# 一、定义

> **任何原因导致气体进入胸膜腔 → 气胸。**

分类：

1. 自发性
    
2. 外伤性
    
3. 医源性
    

自发性：
原发性自发性气胸 PSP
继发性自发性气胸 SSP


---

# 二、气胸为什么危险？⭐⭐⭐

正常：

```text
胸腔负压
→ 牵引肺扩张
→ 促进静脉回心血量
```

气胸：

```text
空气进入胸膜腔
→ 胸腔负压消失
→ 肺萎陷
→ 肺容积↓
→ V/Q下降
→ 低氧血症
```

大量气胸：

```text
胸腔压力↑
→ 静脉回流↓
→ 心脏充盈↓
→ 心排出量↓
→ 血压↓
→ 休克
```

张力性气胸：

> 可导致严重呼吸、循环障碍甚至死亡。

---

# 三、气体进入胸腔的三种机制

1. **肺泡与胸膜腔交通**
    
2. **胸壁与外界交通**
    
3. **胸腔产气微生物**
    

临床以前两者为主。

---

# 四、原发性 vs 继发性自发性气胸

## PSP

发生于：

> 无明显基础肺疾病的人

典型：

> **瘦高型青年男性**

主要机制：

> 胸膜下肺大疱 / 微小疱破裂

危险因素：
吸烟
身高/体型
家族史


---

## SSP

发生于：

> **已有基础肺疾病**

常见：
COPD
肺结核
肺癌
肺脓肿
肺纤维化
LAM等


特点：

> **症状更重、耐受更差、通常需积极干预**

---

# 五、气胸三种临床类型 ⭐⭐⭐⭐⭐

## 1. 闭合性气胸

特点：

> 破口关闭，空气不再进入。

抽气后：

> 胸膜腔压力**不再升高**

---

## 2. 开放性/交通性气胸

特点：

> 破口持续开放，空气可自由进出。

胸腔压力：

> 在 **0 cmH₂O附近波动**

抽气后：

```text
压力暂时下降
→ 很快恢复原水平
```

---

## 3. 张力性气胸 ⭐⭐⭐⭐⭐

机制：

> **单向活瓣**

```text
吸气
→ 空气进入

呼气
→ 空气不能排出

反复循环
→ 胸腔压力持续升高
→ 肺受压
→ 纵隔健侧移位
→ 静脉回流↓
→ 循环障碍
```

胸腔压力常：

```text
>10 cmH₂O
```

甚至可达：

```text
20 cmH₂O
```

特点：

> **抽气后压力下降，但很快重新升高。**

### 一句话

> **张力性气胸 = 气体“只进不出” → 呼吸循环双重危机。**

---

# 六、三型气胸快速鉴别

|类型|破口|空气|抽气后压力|
|---|---|---|---|
|闭合性|已关闭|不再进入|不再升高|
|开放性|持续开放|自由进出|又恢复原值|
|张力性|单向活瓣|**只进不出**|**迅速复升**|

### 口诀

> **闭合“不进”，开放“进出”，张力“只进”。**

---

# 八、气胸体征 ⭐⭐⭐

大量气胸：

```text
气管 → 健侧移位
患侧胸廓 → 隆起
呼吸运动 → ↓
触觉语颤 → ↓
叩诊 → 过清音/鼓音
呼吸音 → ↓或消失
```

### 和胸腔积液对比

||胸腔积液|气胸|
|---|---|---|
|语颤|↓|↓|
|呼吸音|↓|↓|
|叩诊|**浊音**|**鼓音/过清音**|
|大量时纵隔|健侧|健侧|

### 最高频鉴别点

> **胸水叩浊，气胸叩鼓。**

# 九、气胸影像学 ⭐⭐⭐

X线确诊依据：

> **气胸线**

典型：

```text
气胸线以内 → 压缩肺组织
气胸线以外 → 透亮度↑，无肺纹理
```

大量气胸：
肺压缩于肺门
纵隔向健侧移位


---

## 气胸量判断

### 肺尖距离

```text
≥3 cm → 大量
<3 cm → 小量
```

### 侧胸壁—肺边缘距离

```text
1 cm ≈ 25%
2 cm ≈ 50%
```

因此：

```text
≥2 cm → 大量
<2 cm → 小量
```

---

# 十、气胸血气特点

一般：

```text
PaO₂ ↓
PaCO₂ → 正常或↓
```

原因：

> 肺萎陷 → V/Q失衡 → 低氧血症。

---

# 十一、气胸严重程度

## 稳定型

必须**全部满足**：

```text
呼吸频率 <24次/min
心率 60～120次/min
血压正常
室内空气 SaO₂ >90%
能够连续说完整句子
```

不满足任一：

> **不稳定型**

---

# 十二、气胸治疗总原则 ⭐⭐⭐⭐⭐

目标：

1. **促进肺复张**
    
2. **消除病因**
    
3. **减少复发**
    

主要手段：

```text
保守
↓
胸腔穿刺抽气
↓
胸腔闭式引流
↓
胸膜固定
↓
手术
```

---

# 十三、保守治疗

主要适用于：

> **稳定型小量气胸**

教材指征：
肺压缩 <20%
无明显症状
初次发作
CT未发现明显肺大疱
无血胸等并发症


处理：
卧床
观察
吸氧
镇痛、镇静


---

## 为什么吸氧能促进气胸吸收？

```text
吸入高浓度O₂
→ 血液氮分压↓
→ 胸腔—血液氮分压差↑
→ 胸腔N₂进入血液
→ 胸腔气体吸收↑
```

称：

> **氮-氧转换**

---

# 十四、排气治疗 ⭐⭐⭐⭐⭐

## 1. 胸腔穿刺抽气

适用于：
肺压缩 20%～50%
症状较轻
心肺功能较好
闭合性气胸


常用穿刺点：

> **锁骨中线第2肋间**

也可：

> 腋前区第4～6肋间

一次抽气：

```text
≤1000 ml
```

---

## 张力性气胸 ⭐⭐⭐⭐⭐

> **必须立即减压。**

紧急条件下：

> 可直接用粗针刺入胸膜腔减压救命。

### 核心原则

> **先减压救命，不应等待完善检查。**

---

# 十五、胸腔闭式引流

适用于：
不稳定型气胸
明显呼吸困难
肺压缩明显
交通性气胸
张力性气胸
反复气胸
继发性气胸


常用部位：

- 锁骨中线外侧第2肋间
    
- 腋前线第4～5肋间
    

---

## 水封瓶关键数字

引流管末端置于水下：

```text
1～2 cm
```

胸膜腔压力维持：

```text
-1～-2 cmH₂O或以下
```

负压吸引：

```text
-10～-20 cmH₂O
```

---

# 十六、胸膜固定术

机制：

```text
硬化剂
→ 无菌性胸膜炎
→ 脏、壁胸膜粘连
→ 消灭胸膜腔间隙
→ 防止复发
```

适用于不适合/拒绝手术的：

- 持续性气胸
    
- 复发性气胸
    
- 双侧气胸
    
- 合并肺大疱
    
- 肺功能差不能耐受手术者
    

常用：

- 滑石粉
    
- 聚维酮碘
    
- 多西环素
    
- 四环素
    

注意：

> 滑石粉可能导致 **ARDS**。

---

# 十七、气胸手术适应证

考虑：

- 反复发作
    
- 长期气胸
    
- 血气胸
    
- 双侧气胸
    
- 张力性气胸引流失败
    
- 肺膨胀不全
    
- 多发肺大疱
    

常见术式：

> **肺大疱切除 + 胸膜固定术**

---

# 十八、气胸并发症

## 1. 脓气胸

处理：

```text
抗生素
+
胸腔引流
+
必要时手术
```

---

## 2. 血气胸

多数肺复张后可止血。

若持续出血：

> **引流 + 输血 + 手术止血**

---

## 3. 纵隔气肿/皮下气肿

机制：

```text
肺泡破裂
→ 气体进入肺间质
→ 沿血管鞘进入纵隔
→ 进入颈部/胸壁皮下
```

严重纵隔气肿可：

```text
压迫大血管
→ 静脉回流↓
→ 低血压
```

# 十九、胸腔积液 vs 气胸总鉴别 ⭐⭐⭐⭐⭐

|项目|胸腔积液|气胸|
|---|---|---|
|胸膜腔内容物|液体|气体|
|患侧胸廓|饱满|隆起|
|呼吸运动|↓|↓|
|语颤|↓|↓|
|叩诊|**浊音**|**鼓音/过清音**|
|呼吸音|↓/消失|↓/消失|
|大量时纵隔|向健侧|向健侧|
|X线|致密影|透亮区、无肺纹理|
|特征影像|弧形积液上缘|气胸线|

### 口诀

> **“水浊气鼓，水白气黑。”**

即：

```text
胸水 → 叩诊浊音 + X线致密
气胸 → 叩诊鼓音 + X线透亮
```

# 二十、最重要数字集中背诵 ⭐⭐⭐⭐⭐

## 胸腔积液

```text
少量胸水症状不明显：<0.3～0.5 L

Light：
蛋白比 >0.5
LDH比 >0.6
LDH >血清正常上限2/3

ADA >45 IU/L → 支持结核

复杂肺炎旁胸水：
pH <7.2
葡萄糖 <3.3 mmol/L
LDH >1000 IU/L

结核第一次抽液 ≤800 ml
以后每次 ≤1000 ml
```

## 气胸

```text
稳定型：
RR <24/min
HR 60～120/min
SaO₂ >90%

小量保守：
肺压缩 <20%

穿刺抽气：
肺压缩 20%～50%
一次抽气 ≤1000 ml

肺尖气胸线距离 ≥3 cm → 大量

侧胸壁—肺边缘 ≥2 cm → 大量

水封瓶水下：1～2 cm

负压吸引：
-10～-20 cmH₂O
```

# 二十一、考前1分钟总复习

## 胸腔积液

```text
胸水 = 产生↑ 或吸收↓
      ↓
机制六条：
压高、蛋低、膜漏、淋堵、损伤、医源

诊断三步：
有无胸水
→ 漏出还是渗出
→ 找病因

Light：
0.5、0.6、2/3

漏出：
心衰、肾病、肝硬化

渗出三大：
肺炎、结核、肿瘤

复杂肺炎旁：
pH↓、糖↓、LDH↑
```

## 气胸

```text
空气进入胸膜腔
→ 胸腔负压消失
→ 肺萎陷
→ V/Q失衡
→ 低氧

三型：
闭合 = 不再进
开放 = 自由进出
张力 = 只进不出

体征：
语颤↓
鼓音
呼吸音↓

张力性：
纵隔移位
静脉回流↓
心排量↓
休克
→ 立即减压

治疗：
小量稳定 → 观察吸氧
较大闭合 → 穿刺抽气
不稳定/交通/张力 → 闭式引流
反复 → 固定/手术
```

---

# 二十二、一句话建立整章框架

> **胸膜腔最重要的是维持“少量液体 + 负压”这个稳定状态：液体平衡破坏形成胸腔积液，气体进入破坏负压形成气胸；因此胸水的核心是判断“漏出还是渗出”，气胸的核心是判断“是否存在持续漏气和高压”。**
