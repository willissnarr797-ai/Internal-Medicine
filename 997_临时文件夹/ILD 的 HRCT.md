可以。把 ILD 的 HRCT 先压缩成 **6 个高频征象**，你后面做题会很顺：

|HRCT征象|本质|高频疾病|
|---|---|---|
|**磨玻璃影 GGO**|肺泡部分充填/间质轻度增厚|NSIP、HP、DIP、PJP、早期DAD|
|**网格影 reticulation**|间质纤维化/小叶间隔增厚|UIP/IPF、NSIP、CTD-ILD|
|**蜂窝肺 honeycombing**|终末期纤维化和结构破坏|**UIP/IPF最典型**|
|**实变 consolidation**|肺泡内被炎症/机化物填充|**COP/OP**、感染性肺炎|
|**结节 nodules**|肉芽肿/细胞浸润|HP、结节病、PLCH|
|**囊肿 cysts**|肺实质破坏形成含气腔|**LAM、PLCH、LIP**|

---

# 一、磨玻璃影 GGO

定义：

> 肺密度增高，但仍能看见其中的血管和支气管轮廓。

可以理解成：

```text
肺泡并没有完全“填满”
或
间质只是轻度增厚
↓
所以肺变白了
但血管还能看见
```

## 最常见的 ILD

### 1. NSIP

典型：

```text
双下肺
+ 对称
+ 磨玻璃影
+ 细网格
+ 牵拉性支扩
```

尤其：

> **磨玻璃影较多，而蜂窝肺较少。**

---

### 2. 过敏性肺炎 HP

尤其非纤维化型：

```text
磨玻璃影
+ 小叶中心结节
+ 马赛克衰减
+ 气体潴留
```

所以：

> **GGO + 小气道征象 → 考虑 HP。**

---

### 3. DIP

典型：

> 吸烟者 + 双下肺/外周磨玻璃影。

---

# 二、网格影 Reticulation

看到肺内很多交织的细线：

```text
─────
╲ ╱
─╳──
╱ ╲
```

提示：

> **间质结构增厚。**

主要来自：

- 小叶间隔增厚
    
- 小叶内间质增厚
    
- 纤维化
    

---

## 最重要的两个疾病

### UIP/IPF

```text
胸膜下
+ 肺底
+ 粗网格
+ 牵拉支扩
+ 蜂窝肺
```

### NSIP

也有网格影，但：

```text
更对称
+
磨玻璃更多
+
蜂窝肺更少
```

所以：

> **网格 + 蜂窝 → UIP优先**

> **网格 + 大量GGO → NSIP优先**

---

# 三、蜂窝肺 Honeycombing

这是学习 ILD 必须彻底理解的征象。

不是“蜂窝状阴影”这么简单，而是：

> **肺组织已经发生不可逆结构性破坏。**

HRCT表现为：

- 胸膜下
    
- 成簇
    
- 多层
    
- 厚壁或较清晰壁
    
- 大约数毫米到1 cm左右的囊样含气腔
    

像：

```text
胸膜
│○○○○
│ ○○○
│○○○○
```

---

## 最经典

### UIP / IPF

如果看到：

> 老年患者 + 双肺基底部 + 胸膜下 + 蜂窝肺

首先想到：

**UIP模式。**

如果又：

- 没有结缔组织病
    
- 没有药物因素
    
- 没有明确职业/环境暴露
    

才进一步支持：

> **IPF。**

这一层关系要记：

```text
蜂窝肺
↓
考虑纤维化 ILD
↓
HRCT符合 UIP
↓
排除已知病因
↓
IPF
```

---

# 四、实变 Consolidation

和磨玻璃影区别非常重要。

### 磨玻璃

血管还能看见。

### 实变

肺泡被完全填充：

```text
炎性渗出物
细胞
蛋白
机化组织
↓
肺泡空气消失
↓
实变
```

所以其中血管常被遮住。

---

## ILD里面最重要：

### COP / OP

典型：

```text
双肺
+
外周/胸膜下
+
斑片状实变
+
可以迁徙
```

临床：

```text
咳嗽、发热
↓
看起来像肺炎
↓
抗生素没效果
↓
病灶还会换地方
↓
考虑 COP
```

因此做题：

> **游走性实变 = OP/COP 高度提示。**

---

# 五、结节 Nodules

在 ILD 里不能只看到“结节”，还一定要问：

> **结节在哪里？**

这是影像诊断非常重要的思想。

肺小叶可以简单画成：

```text
      胸膜
────────────
|          |
|  ·    ·  | ← 小叶中心
|          |
|───────|  ← 小叶间隔
```

于是结节分布主要有：

### ① 小叶中心性

典型：

> **HP**

因为吸入性抗原从：

```text
气道
↓
细支气管
↓
肺泡
```

进入。

所以容易围绕细支气管形成炎症。

---

### ② 淋巴管周围分布

典型：

> **结节病**

常沿：

- 支气管血管束
    
- 小叶间隔
    
- 胸膜下
    

出现。

同时：

> 双侧肺门淋巴结肿大

非常经典。

---

### ③ 结节 + 囊肿

想到：

> **PLCH**

尤其：

```text
年轻吸烟者
+
上肺结节
+
空洞结节
+
不规则囊肿
```

---

# 六、囊肿 Cysts

ILD/弥漫性肺疾病中看到大量囊肿，首先考虑三个：

```text
LAM
PLCH
LIP
```

这三个非常适合一起鉴别。

|特点|LAM|PLCH|LIP|
|---|---|---|---|
|人群|**育龄女性**|**年轻吸烟者**|自身免疫病|
|囊肿形态|圆、薄壁、均匀|奇形怪状|薄壁、大小不等|
|分布|**全肺均匀**|**上中肺**|常下肺/弥漫|
|肋膈角|累及|**相对保留**|可累及|
|结节|少|**常有**|可有|
|GGO|少|较少|**常有**|
|重要关联|TSC、肾AML|吸烟|**干燥综合征**|
|其他|气胸、乳糜胸|气胸|自身免疫表现|

所以三个经典病例：

```text
年轻女性 + 全肺均匀薄壁囊肿
→ LAM

年轻吸烟者 + 上肺奇形囊肿 + 结节
→ PLCH

干燥综合征 + 磨玻璃 + 薄壁囊肿
→ LIP
```

---

# 七、把六种影像组合起来

真正做题不要单独认一个征象，而要认“组合”。

## UIP/IPF

```text
网格影
+
牵拉性支扩
+
蜂窝肺
+
肺底、胸膜下
```

关键词：

> **老年 + 基底 + 胸膜下 + 蜂窝**

---

## NSIP

```text
磨玻璃
+
细网格
+
牵拉支扩
+
蜂窝少
+
双下肺对称
```

关键词：

> **GGO + 对称 + CTD**

---

## HP

```text
磨玻璃
+
小叶中心结节
+
马赛克
+
气体潴留
```

关键词：

> **抗原暴露 + 小气道病变**

---

## COP

```text
外周实变
+
磨玻璃
+
游走性
```

关键词：

> **像肺炎，但抗生素没用。**

---

## LAM

```text
全肺
+
均匀
+
圆形薄壁囊肿
```

关键词：

> **育龄女性。**

---

## PLCH

```text
上中肺
+
结节
+
空洞
+
奇形囊肿
+
肋膈角保留
```

关键词：

> **年轻吸烟者。**

---

# 八、最终形成你的 ILD 读片算法

以后看到 HRCT，可以固定按照这个顺序：

```text
第一步：主要是什么影？
        ↓
GGO / 网格 / 蜂窝 / 实变 / 结节 / 囊肿

第二步：在哪里？
        ↓
上肺还是下肺？
中央还是外周？
胸膜下还是小叶中心？
均匀还是不均匀？

第三步：有没有伴随征象？
        ↓
牵拉性支扩
气体潴留
马赛克
淋巴结肿大
胸腔积液
结节

第四步：结合患者是谁
        ↓
年龄
性别
吸烟
职业
鸟类/霉菌暴露
自身免疫病
药物史

第五步：形成疾病模式
```

最后可以进一步压成一句：

> **“先认征象，再看分布，再看组合，最后套临床背景。”**

这其实就是以后学习胸部影像学、呼吸内科乃至考研病例题时非常通用的思路。
