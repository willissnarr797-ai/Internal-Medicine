除了肺上沟瘤，**Horner 综合征的病因很多**。最好按交感神经通路的损害位置来记。

Horner 的交感神经通路大致是：

**下丘脑 → 脑干 → C8–T2 脊髓侧角 → 颈交感链 → 颈上神经节 → 沿颈内动脉进入颅内 → 眼**

因此任何一段受损都可能导致 Horner 综合征。

|损害部位|常见疾病|
|---|---|
|**中枢性**|脑干梗死，尤其是**延髓外侧综合征（Wallenberg）**；脑干肿瘤；多发性硬化；脊髓空洞症；颈髓肿瘤或损伤|
|**节前性**|**肺上沟瘤（Pancoast tumor）**；纵隔肿瘤；甲状腺或颈部肿瘤；颈部外伤；胸廓出口病变；颈胸部手术损伤|
|**节后性**|**颈内动脉夹层**；颈内动脉瘤；海绵窦病变；颅底肿瘤；丛集性头痛等|

其中有几个是临床和考试特别重要的。

**1. 延髓外侧综合征（Wallenberg syndrome）**

延髓外侧梗死损伤下行交感神经纤维：

**PICA / 椎动脉梗死 → 延髓外侧损伤 → 同侧 Horner 综合征**

通常还伴有眩晕、吞咽困难、声音嘶哑、共济失调，以及交叉性感觉障碍。

所以如果看到：

**Horner + 吞咽困难 + 眩晕 + 共济失调**

要考虑 **Wallenberg 综合征**。

**2. 颈内动脉夹层**

这是非常重要的急症。

典型表现：

**一侧头颈部疼痛 + 同侧 Horner 综合征**

尤其是突然发生时，应首先排除**颈内动脉夹层**。

这种 Horner 往往是“部分性”的，即：

**瞳孔缩小 + 轻度上睑下垂，但面部无汗不明显**

因为控制面部汗腺的部分交感纤维主要随颈外动脉走，而眼部交感纤维随颈内动脉走。

**3. 肺上沟瘤**

这是内科学肺癌部分最常考的：

**肺尖部肺癌**  
→ 侵犯 C8、T1 臂丛  
→ 肩部及上肢尺侧疼痛

同时：

**侵犯颈交感链**  
→ Horner 综合征

因此形成经典组合：

> **肺尖部肿块 + 肩臂痛 + Horner 综合征 = Pancoast 瘤**

**4. 脊髓空洞症**

如果病变累及 **C8–T2 脊髓交感神经元**，也可出现 Horner，同时可能出现典型的**分离性感觉障碍**。

### 一个非常实用的定位记忆

可以把 Horner 想成“三段电线”：

```text
第一段：脑
下丘脑 → 脑干 → 脊髓
损坏：脑干梗死、肿瘤、脱髓鞘

第二段：胸颈部
脊髓 → 肺尖 → 颈交感链
损坏：Pancoast瘤、纵隔/颈部肿瘤、外伤

第三段：颈内动脉周围
颈上神经节 → 颈内动脉 → 眼
损坏：颈内动脉夹层、海绵窦/颅底病变
```

考试中最值得记住的三个病因就是：

**Pancoast 瘤 → Wallenberg 综合征 → 颈内动脉夹层。**

其中如果是**突然出现 Horner + 同侧颈痛/头痛**，临床上要优先考虑**颈内动脉夹层**，因为它存在脑卒中风险。
