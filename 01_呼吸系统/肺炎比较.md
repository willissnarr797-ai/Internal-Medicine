
可以把前面“肺炎”整章压缩成 **3层分类 + 1张病原体对比表 + 1条临床决策链**。这样最适合内科学复习。

# 一、先把“肺炎分类”分清楚

肺炎的分类其实是在回答三个不同问题：

|分类方式|核心问题|主要类型|临床意义|
|---|---|---|---|
|按解剖|**炎症在哪**|大叶性、小叶性、间质性|理解病理和影像|
|按病因|**谁引起的**|细菌、病毒、支原体等、真菌|判断病原体和用药|
|按环境|**在哪里得的**|CAP、HAP、VAP|决定经验性抗感染策略|

可以直接记成：

```text
解剖分类 = 长在哪
病因分类 = 谁引起
环境分类 = 在哪感染
```

其中内科学临床思维最重要的是：

> **患病环境 → 可能病原体 → 严重程度 → 病原学检查 → 经验性治疗**

---

# 二、按解剖分类对比

## 1. 大叶性肺炎

核心病变：

> 以肺泡炎症、实变为主，可累及一个肺段或肺叶。

典型：

> 肺炎链球菌肺炎

病理逻辑：

```text
肺泡渗出
↓
大量肺泡腔被炎性渗出物填充
↓
肺实变
↓
大叶/肺段性阴影
```

所以临床常见：

- 高热
    
- 寒战
    
- 胸痛
    
- 咳嗽
    
- 咳痰
    
- 实变体征
    

---

## 2. 小叶性肺炎

又称：

> **支气管肺炎**

病变中心：

> 细支气管及其周围肺组织。

因此呈：

```text
多个细支气管周围炎症
↓
多个小叶受累
↓
斑片状分布
```

不像典型大叶性肺炎那样整齐地占据整个肺叶。

---

## 3. 间质性肺炎

主要侵犯：

- 肺泡壁
    
- 肺间质
    

而不是主要把肺泡腔“灌满”。

常见：

- 病毒性肺炎
    
- 支原体肺炎等
    

因此：

```text
肺间质炎症/水肿
↓
肺泡-毛细血管膜增厚
↓
气体弥散受影响
↓
低氧血症
```

这也是为什么病毒性肺炎影像常容易出现：

> 磨玻璃影、间质性改变。

---

# 三、按病原体分类：最重要的临床对比

## 总表

|类型|典型人群/线索|起病|痰|胸部体征|影像特点|特殊点|治疗逻辑|
|---|---|---|---|---|---|---|---|
|肺炎链球菌|健康成人、典型CAP|**急**|**铁锈色痰**|实变较明显|大叶/肺段实变|一般不形成空洞|β-内酰胺类思路|
|葡萄球菌|重症、毒血症明显|急|脓性/血性|较明显|**坏死、空洞、肺气囊、脓胸**|破坏性强|注意MRSA|
|支原体|**儿童、青年**|**较缓**|**干咳为主**|**体征较轻**|斑片/间质改变|无细胞壁|β-内酰胺无效|
|衣原体|青年，可有上呼吸道症状|缓|干咳|较轻|间质/斑片|可呈双相病程|大环内酯等|
|军团菌|水源暴露、老人、吸烟、免疫低下|较急|可有|肺炎较重|浸润影|**腹泻+神经症状**|大环内酯/喹诺酮|
|病毒|流行病学接触|变化大|多干咳|有时体征少|**间质/GGO**|可出现低氧|抗病毒+支持|
|真菌|**免疫抑制**|多亚急/慢性|不典型|不典型|结节、空洞、弥漫影等|与宿主状态密切相关|抗真菌|

# 四、肺炎链球菌 vs 葡萄球菌

这是最值得单独比较的一组。

## 肺炎链球菌

典型画像：

```text
急起
+
寒战高热
+
胸痛
+
铁锈色痰
+
大叶性实变
+
通常无空洞
```

病理经典四期：

```text
充血期
↓
红色肝样变期
↓
灰色肝样变期
↓
消散期
```

特点是：

> 肺泡大量炎性渗出，但肺组织结构通常不发生明显坏死，所以一般不会留下明显瘢痕。

---

## 葡萄球菌

典型画像：

```text
高热
+
毒血症重
+
脓性/血性痰
+
肺组织坏死
+
空洞
+
肺脓肿
+
肺气囊
+
脓胸
```

核心区别其实是：

> **葡萄球菌更容易破坏肺组织。**

### 一句话

```text
肺炎链球菌 → 实变
葡萄球菌 → 坏死
```

肺炎链球菌典型表现包括急性高热、寒战、胸痛、铁锈色痰及肺叶/肺段实变；葡萄球菌肺炎则更突出坏死、空洞、肺脓肿和脓胸等破坏性改变。

---

# 五、典型肺炎 vs 非典型肺炎

这是考试非常常见的理解方式。

## 典型细菌性肺炎

例如：

> 肺炎链球菌

特点：

```text
起病急
高热寒战
脓痰/铁锈色痰
肺部体征明显
白细胞明显升高
实变影明显
```

---

## 非典型肺炎

典型代表：

- 支原体
    
- 衣原体
    
- 军团菌
    

共同趋势：

```text
咳嗽突出
+
肺部体征与影像可能不一致
+
常有肺外表现
```

但三者也不能混在一起。

---

# 六、支原体 vs 衣原体 vs 军团菌

## 1. 支原体肺炎 ★★★★★

看到这些就想到支原体：

```text
年轻人
+
缓慢起病
+
阵发性干咳
+
夜间明显
+
肺部体征轻
+
影像改变相对明显
```

最重要机制：

> **支原体没有细胞壁。**

所以：

```text
无细胞壁
↓
β-内酰胺类没有作用靶点
↓
青霉素/头孢类无效
```

这是非常重要的考试点。

---

## 2. 衣原体肺炎

特点相对没有支原体那么“典型”。

可以记：

```text
起病较缓
+
上呼吸道症状
+
持续干咳
+
可出现上下呼吸道双相过程
```

如果：

> β-内酰胺治疗没效果 + 持续干咳

可考虑衣原体、支原体等非典型病原体。

---

## 3. 军团菌肺炎 ★★★★★

最有辨识度。

先问：

> **有没有水环境暴露？**

例如：

- 空调冷却塔
    
- 淋浴
    
- 温泉
    
- 酒店供水系统等
    

再看：

```text
肺炎
+
腹泻
+
恶心/呕吐
+
头痛
+
意识改变
```

也就是：

> **肺症状 + 肺外症状特别明显。**

口诀：

> **军团菌不仅打肺，还打全身。**

军团菌与水环境气溶胶暴露相关，老年、吸烟、慢病或免疫受损者风险较高，且腹泻、恶心呕吐、意识状态变化等肺外表现较突出。

---

# 七、病毒性肺炎

和典型细菌性肺炎相比，病毒更容易表现成：

```text
病毒感染肺泡上皮/气道上皮
↓
细支气管炎
+
间质炎症
↓
肺泡-毛细血管膜增厚
↓
弥散障碍
↓
低氧血症
```

所以影像：

> **间质性改变、磨玻璃影比较突出。**

而不一定是非常典型的整叶实变。

---

# 八、真菌性肺炎：不要按菌死背

真菌性肺炎最重要的第一问不是：

> “什么真菌？”

而是：

> **病人的免疫状态怎么样？**

因为肺真菌病与宿主状态关系极强。教材强调诊断要综合宿主因素、临床表现、微生物学和病理学，而组织病理学证据尤其重要。

---

# 九、曲霉病三种状态 ★★★★★

曲霉最适合按宿主状态来记。

## IPA——侵袭性肺曲霉病

典型：

> **严重免疫抑制患者**

影像：

```text
早期 → 晕轮征 halo sign
后期 → 空气新月征
```

---

## 曲霉球

前提：

> 肺内已经有一个空洞。

然后：

```text
曲霉在旧空洞内生长
↓
形成真菌球
```

典型：

- 咯血
    
- 真菌球可随体位变化
    

即：

> **Monod征**

---

## ABPA

典型宿主：

> 哮喘患者。

核心组合：

```text
哮喘
+
嗜酸性粒细胞↑
+
总IgE↑
+
曲霉致敏
+
中央型支气管扩张
```

所以：

> **同样是曲霉，免疫状态不同 → 疾病完全不同。**

---

# 十、PCP 肺炎 ★★★★

PCP = Pneumocystis jirovecii pneumonia。

典型：

```text
免疫缺陷
+
干咳
+
进行性呼吸困难
+
明显低氧
+
双肺弥漫性阴影
```

很重要的特点：

> **症状很重，但肺部体征可能不明显。**

即：

```text
症状重
≠
体征重
```

也就是所谓：

> **症状与体征分离。**

---

# 十一、按患病环境比较

## CAP

社区获得性肺炎。

重点考虑：

- 肺炎链球菌
    
- 支原体
    
- 衣原体
    
- 军团菌
    
- 病毒等
    

---

## HAP

医院获得性肺炎：

> 入院 **≥48 h** 后发生，且入院时不存在也不处于潜伏期。

关注重点开始变化：

```text
医院环境
↓
耐药菌风险增加
↓
经验性抗菌药选择更复杂
```

---

## VAP

呼吸机相关肺炎：

> 有创机械通气 ≥48 h 后发生。

可以理解：

```text
HAP
+
人工气道
+
机械通气
↓
特殊的病原体和耐药风险
```

CAP、HAP 和 VAP 的环境分类，本质上是为了帮助判断潜在病原体及耐药风险。

---

# 十二、整章最高频“识别模式”

建议最终背成这张：

|看到病例关键词|首先想到|
|---|---|
|高热寒战 + 铁锈色痰 + 大叶实变|**肺炎链球菌**|
|脓血痰 + 空洞 + 肺脓肿 + 脓胸|**葡萄球菌**|
|青年 + 阵发干咳 + 体征轻|**支原体**|
|干咳 + β-内酰胺效果差|支原体/衣原体|
|水环境 + 肺炎 + 腹泻/意识改变|**军团菌**|
|流行病接触 + GGO/间质改变|**病毒性肺炎**|
|严重免疫抑制 + halo sign|**侵袭性曲霉病**|
|旧肺空洞 + 可移动真菌球 + 咯血|**曲霉球**|
|哮喘 + IgE↑ + 嗜酸↑ + 中央支扩|**ABPA**|
|免疫缺陷 + 干咳 + 进行性呼吸困难 + 体征轻|**PCP**|

# 十三、最终背诵总纲

```text
肺炎分类
│
├─ 按解剖
│   ├─ 大叶性
│   ├─ 小叶性
│   └─ 间质性
│
├─ 按病因
│   ├─ 细菌
│   │   ├─ 肺炎链球菌 → 实变、铁锈色痰
│   │   └─ 葡萄球菌 → 坏死、空洞
│   │
│   ├─ 非典型
│   │   ├─ 支原体 → 青年、干咳、无细胞壁
│   │   ├─ 衣原体 → 缓起、持续干咳
│   │   └─ 军团菌 → 水源 + 肺外症状
│   │
│   ├─ 病毒
│   │   └─ 间质/GGO + 低氧
│   │
│   └─ 真菌
│       ├─ 曲霉
│       ├─ 隐球菌
│       ├─ 念珠菌
│       └─ PCP
│
└─ 按环境
    ├─ CAP
    ├─ HAP
    └─ VAP
```

最关键的是把整章转化成：

> **“什么样的人 + 怎么起病 + 什么痰 + 有没有肺外表现 + 影像什么样 + 有没有空洞 → 最像哪个病原体？”**

这样病例题基本就从“背疾病”转化成了**模式识别**。
