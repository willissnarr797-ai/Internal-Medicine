# 二、学习顺序

## 第一轮：搭建框架

先学：

1. 肺癌定义
    
2. 中央型 vs 周围型
    
3. NSCLC vs SCLC
    
4. 鳞癌 vs 腺癌 vs 小细胞癌
    
5. 临床表现四大类
    

### 第一轮目标

闭眼能够说出：

```text
肺癌
→ 病理类型
→ 生长位置
→ 临床表现
→ 影像
→ 病理确诊
→ 分期
→ 治疗
```

第一轮**暂时不要死背靶向药和TNM细节**。

---

# 三、第二轮：建立三大病理类型画像

这是本章第一核心。

## 1. 鳞癌

### 关键词

```text
老年男性
+
中央型
+
支气管腔内生长
+
阻塞
+
坏死、空洞
+
生长较慢
+
转移较晚
```

### 机制链

```text
段/亚段支气管
↓
向管腔生长
↓
支气管狭窄/阻塞
↓
肺不张
或
阻塞性肺炎
↓
癌组织坏死
↓
癌性空洞
```

### 临床特点

- 常见于老年男性
    
- 多为中央型
    
- 生长较慢
    
- 转移较晚
    
- 手术机会相对较多
    
- 对放化疗敏感性不如 SCLC
    

---

## 2. 腺癌

### 关键词

```text
最常见
+
女性较多
+
周围型
+
肺边缘结节/肿块
+
血管丰富
+
血行转移早
+
胸膜侵犯
+
胸腔积液
```

### 机制链

```text
细小支气管/肺周边
↓
周围型肿块
↓
血管丰富
↓
较早血行转移

同时
↓
靠近胸膜
↓
胸膜侵犯
↓
胸腔积液
```

---

## 3. 小细胞肺癌 SCLC

### 关键词

```text
低分化
+
神经内分泌
+
中央型
+
增殖快
+
转移早
+
化疗敏感
+
放疗敏感
```

### 最核心特点

```text
SCLC
↓
长得快
↓
转移早
↓
发现时往往已经不是局限病灶
↓
通常不以手术为主要治疗
↓
化疗 + 放疗非常重要
```

SCLC 初诊时已有很高比例发生脑、肝、骨或肾上腺等转移，而其对化疗和放疗较敏感。

---

# 四、三大类型对比表 ★★★★★

|特点|鳞癌|腺癌|SCLC|
|---|---|---|---|
|常见位置|中央|**周围**|中央|
|人群特点|老年男性|女性较多|—|
|生长|较慢|—|**很快**|
|转移|较晚|**血行转移较早**|**极早**|
|空洞|常见|可有|非核心特点|
|胸膜侵犯|—|常见|—|
|放化疗|较低|—|**敏感**|
|手术|较多机会|早期可手术|通常不手术|

### 一句话

> **鳞癌堵，腺癌跑，小细胞又快又爱跑。**

---

# 五、中央型 vs 周围型 ★★★★★

## 中央型

```text
段及以上支气管
```

常见：

- 鳞癌
    
- SCLC
    

容易产生：

```text
支气管阻塞
↓
肺不张
↓
阻塞性肺炎
```

## 周围型

```text
段支气管以下
```

常见：

> **腺癌**

教材明确将中央型定义为发生于段及以上支气管，而周围型发生于段支气管以下。

---

# 六、危险因素 ★★★

## 最重要：吸烟

```text
肺癌危险因素
├─ 吸烟 ★★★★★
├─ 职业致癌物
├─ 空气污染
├─ 电离辐射
├─ 饮食与体力活动
├─ 遗传/基因改变
└─ 慢性肺部疾病等
```

## 职业致癌物

重点记：

```text
石棉
砷
铬
镍
氡
镉
铍
多环芳烃
```

不需要第一轮逐个背全部。

### 发病机制核心

```text
外界致癌因素
↓
DNA/基因损伤
↓
原癌基因激活
+
抑癌基因失活
↓
细胞增殖失控
+
凋亡障碍
+
血管生成
+
免疫逃逸
↓
肺癌
```

吸烟是教材列出的最主要危险因素，同时还包括职业暴露、空气污染、电离辐射以及遗传与基因改变等。

---

# 七、临床表现 ★★★★★

不要把症状混着背。

分成 **4 大类**：

```text
肺癌症状
├─ ① 原发肿瘤
├─ ② 局部扩展
├─ ③ 远处转移
└─ ④ 副肿瘤综合征
```

---

# 八、① 原发肿瘤症状

背：

```text
咳
血
喘
痛
热
瘦
```

即：

1. 咳嗽
    
2. 痰血/咯血
    
3. 气短/喘鸣
    
4. 胸痛
    
5. 发热
    
6. 消瘦
    

## 咳嗽

早期常见：

> 无痰或少痰的刺激性干咳

支气管狭窄后：

> 咳嗽加重。

## 咯血

尤其提示：

> **中央型肺癌**

## 发热

常见原因：

```text
肿瘤坏死
或
支气管阻塞
↓
阻塞性肺炎
```

特点：

> 抗菌治疗效果可能不佳。

原发肿瘤的六组表现及其机制见教材总结。

---

# 九、② 局部侵犯症状 ★★★★★

这一部分建议用“肿瘤压到了谁”理解。

## 喉返神经

```text
压迫喉返神经
↓
声带麻痹
↓
声音嘶哑
```

尤其：

> 左侧较多。

---

## 食管

```text
侵犯/压迫食管
↓
吞咽困难
```

---

## 胸膜

```text
胸膜侵犯
↓
胸痛
+
胸腔积液
```

---

## 心包

```text
心包侵犯
↓
心包积液
↓
严重时心脏压塞
```

---

## 上腔静脉

```text
上腔静脉受压
↓
静脉回流受阻
↓
颈面部 + 上肢水肿
+
胸壁静脉曲张
```

### = 上腔静脉阻塞综合征

---

# 十、Pancoast 瘤 + Horner 综合征 ★★★★★

## 肺上沟瘤

位置：

> 肺尖。

压迫：

> 颈交感神经。

产生：

```text
Horner 综合征
├─ 眼睑下垂
├─ 瞳孔缩小
├─ 眼球内陷
└─ 同侧少汗/无汗
```

### 记忆

```text
肺尖
↓
交感神经
↓
眼睛 + 出汗
```

教材将声音嘶哑、上腔静脉阻塞以及肺上沟瘤导致 Horner 综合征归入局部扩展表现。

---

# 十一、③ 远处转移

重点四处：

```text
脑
骨
肝/腹部器官
淋巴结
```

## 脑转移

```text
头痛
恶心
呕吐
癫痫
局灶神经功能缺损
```

## 骨转移

```text
疼痛
压痛

```

常见：

- 肋骨
    
- 脊柱
    
- 骨盆
    
- 长骨
    

## 肝等腹部转移

可出现：

- 肝区痛
    
- 黄疸
    
- 肝大
    
- 腹水
    

## 淋巴结

典型：

> **锁骨上淋巴结**

特点：

```text
质硬
固定
逐渐增大
多无痛
```

# 十二、④ 副肿瘤综合征 ★★★★★

定义：

> **不是因为肿瘤直接侵犯或转移造成的全身表现。**

尤其多见：

> **SCLC**

---

# 十三、副肿瘤综合征重点组合

## SCLC → SIADH

```text
ADH↑
↓
水潴留
↓
低钠
+
低渗
```

可出现：

- 恶心
    
- 呕吐
    
- 嗜睡
    
- 意识障碍
    
- 癫痫
    
- 昏迷
    

---

## SCLC → 异位 ACTH

```text
ACTH↑
↓
Cushing syndrome
```

可表现：

- 色素沉着
    
- 水肿
    
- 肌萎缩
    
- 低钾
    
- 代谢性碱中毒
    
- 高血糖
    
- 高血压
    

---

## 鳞癌 → 高钙血症

### 高频组合

> **鳞癌 → 高钙血症**

---

## SCLC → Lambert-Eaton

表现：

```text
近端肌无力
+
腱反射减弱
+
反复活动后肌力暂时改善
```

### 高频配对

```text
SCLC
├─ SIADH
├─ 异位ACTH
└─ Lambert-Eaton

鳞癌
└─ 高钙血症
```

副肿瘤综合征以 SCLC 更多见；教材特别列出了 SIADH、异位 ACTH、高钙血症及 Lambert-Eaton 综合征。

# 十四、影像学 ★★★★

## 中央型肺癌

重点：

```text
肺门肿块
+
支气管阻塞
↓
肺气肿
肺不张
阻塞性肺炎
肺脓肿
```

### 特征

> 右上叶中央型肺癌可出现 **倒 S 征**。

---

## 周围型肺癌

关键词：

```text
结节/肿块
+
分叶
+
毛刺
+
脐凹
+
胸膜牵拉
```

癌性空洞：

```text
厚壁
偏心
内壁凹凸不平
```

### 高频影像组合

> **分叶 + 毛刺 + 胸膜牵拉 → 警惕周围型肺癌**

教材对中央型和周围型肺癌的影像特点进行了明确区分。

# 十五、各种影像检查怎么选

## X线

优点：

- 简单
    
- 常用
    

缺点：

> 微小病灶检出能力有限。

---

## CT ★★★★★

核心地位：

```text
发现病灶
+
确定位置
+
看淋巴结
+
评估侵犯
+
帮助分期
+
指导穿刺
```

### LDCT

用于：

> **早期肺癌筛查。**

---

## MRI

特别适合：

```text
肿瘤与大血管关系
+
脑/脑膜转移
```

---

## PET-CT

核心：

```text
代谢
+
解剖定位
```

适合：

- 转移灶
    
- 分期
    
- 疗效评价
    

但：

> **PET-CT 阳性 ≠ 病理确诊。**

最终仍需细胞学/病理学证据。

---

# 十六、肺癌诊断三步法 ★★★★★

直接背：

```text
CT定位
↓
病理定性
↓
分子分型
```

## ① CT确定部位

看：

- 原发灶
    
- 淋巴结
    
- 转移
    

## ② 组织病理学确诊

> **病理是关键。**

获取方式：

```text
中央病变
→ 支气管镜

周围靠近胸壁
→ CT引导经皮穿刺

胸腔积液
→ 胸液细胞学

浅表淋巴结
→ 淋巴结活检

胸膜病变
→ 胸腔镜
```

## ③ 分子病理

尤其 NSCLC：

```text
EGFR
ALK
ROS1
BRAF
RET
MET
KRAS
NTRK
PD-L1
```

肺癌的教材诊断流程就是 **CT定位 → 组织病理学诊断 → 分子病理学诊断**。

---

# 十七、肿瘤标志物

重点记：

```text
CEA
NSE
CYFRA21-1
ProGRP
```

但必须同时背：

> **目前没有敏感性和特异性足够高、可以单独确诊肺癌的肿瘤标志物。**

---

# 十八、鉴别诊断 ★★★

主要：

```text
肺癌
├─ 肺结核
├─ 肺炎
├─ 肺脓肿
├─ 结核性胸膜炎
├─ 肺隐球菌病
└─ 良性肿瘤/淋巴瘤
```

## 肺癌 vs 肺炎

警惕：

```text
抗感染后阴影长期不吸收
或
同一位置反复肺炎
↓
考虑阻塞性肺炎
↓
寻找肺癌
```

## 癌性空洞 vs 肺脓肿

### 肺脓肿

```text
急起
高热
明显中毒
大量脓臭痰
液平
```

### 癌性空洞

```text
厚壁
偏心
内壁凹凸
```

教材特别强调同一部位反复肺炎及厚壁偏心空洞对肺癌鉴别的意义。

# 十九、TNM 分期 ★★★★★

这是第三轮再重点背。

先理解：

```text
T = Tumor
原发肿瘤

N = Node
淋巴结

M = Metastasis
远处转移
```

---

# 二十、T分期——先背尺寸

```text
T1 ≤3 cm

T2 >3～5 cm

T3 >5～7 cm

T4 >7 cm
```

## T1细分

```text
T1a ≤1
T1b >1～2
T1c >2～3
```

## T2细分

```text
T2a >3～4
T2b >4～5
```

### 第一轮背尺寸即可。

第二轮再挂：

```text
T2
→ 主支气管
→ 脏胸膜
→ 阻塞性肺炎/肺不张等

T3
→ 胸壁
→ 膈神经
→ 心包
→ 同叶癌结节等

T4
→ 纵隔
→ 心脏/大血管
→ 隆突
→ 喉返神经
→ 气管
→ 食管
→ 椎体
→ 膈肌
→ 同侧不同肺叶癌结节
```

教材所用 TNM 系统将 T1/T2/T3/T4 的大小节点分别设置在 3、5、7 cm，并同时考虑邻近结构侵犯。

---

# 二十一、N分期

建议用“越来越远”记忆：

```text
N0
无

↓

N1
同侧肺门/支气管周围/肺内

↓

N2
同侧纵隔/隆突下

↓

N3
对侧纵隔
对侧肺门
锁骨上等
```

口诀：

> **N1肺门，N2同侧纵隔，N3跑到对侧/锁骨上。**

---

# 二十二、M分期

```text
M0
无远处转移

M1
有转移
```

重点：

### M1a

> 胸腔内播散

包括：

- 恶性胸腔积液
    
- 恶性心包积液
    
- 胸膜结节
    
- 对侧肺结节
    

### M1b

> 胸外单发转移。

### M1c

> 多发转移。

---

# 二十三、SCLC分期

除了TNM，还可以分：

```text
局限期
vs
广泛期
```

## 局限期

> 病变局限于同侧半胸，并可被单一放射野安全包围。

## 广泛期

> 超过上述范围，包括恶性胸腔/心包积液或血行转移。

---

# 二十四、治疗总原则 ★★★★★

不要一开始背药名。

首先背：

```text
病理类型
+
临床分期
+
分子病理
+
PS评分
↓
决定治疗
```

治疗手段：

```text
手术
化疗
靶向
免疫
放疗
```

肺癌治疗强调根据 PS、病理及分子病理、临床分期实施多学科和个体化治疗。

# 二十六、靶向治疗背诵框架

第一轮不要背每个药。

先背：

```text
EGFR → EGFR-TKI
ALK  → ALK抑制剂
ROS1 → 相应靶向药
BRAF → 相应靶向药
RET  → 相应靶向药
MET  → 相应靶向药
```

## EGFR

教材列举：

- 奥希替尼
    
- 阿美替尼
    
- 厄洛替尼
    
- 吉非替尼
    
- 阿法替尼
    

## ALK

教材列举：

- 克唑替尼
    
- 艾乐替尼
    
- 色瑞替尼
    
- 洛拉替尼
    
- 恩沙替尼
    

### 核心思想

> **不是背“肺癌吃什么靶向药”，而是“先检测基因 → 再匹配药物”。**

教材强调靶向治疗成功的关键在于选择具有相应分子靶点的人群。

---

# 二十七、免疫治疗

核心靶点：

```text
PD-1
↕
PD-L1
```

肿瘤利用免疫检查点：

```text
抑制T细胞
↓
免疫逃逸
```

免疫检查点抑制剂：

```text
阻断PD-1/PD-L1
↓
恢复抗肿瘤免疫
```

对于驱动基因阴性的晚期 NSCLC，PD-L1 表达水平可参与免疫治疗选择。

# 二十八、SCLC治疗 ★★★★★

牢记一句：

> **小细胞肺癌：一般不手术，化疗是基础，放疗很重要。**

## 一线化疗框架

```text
依托泊苷
或
伊立替康

+

顺铂
或
卡铂
```

## 局限期

```text
化疗
+
放疗
```

## 广泛期

```text
化疗
+
免疫治疗
```

极少数：

```text
T1～2N0
↓
可以考虑手术
↓
术后仍需含铂化疗
```

# 二十九、NSCLC vs SCLC治疗比较 ★★★★★

||NSCLC|SCLC|
|---|---|---|
|手术|**早期重要**|通常不做|
|化疗|有重要作用|**核心治疗**|
|放疗|局晚期/辅助/姑息等|**非常敏感**|
|靶向|**重要**|非核心|
|免疫|重要|广泛期可联合|
|分子检测|**非常重要**|相对次要|

# 三十、放疗

主要用途：

```text
根治
姑息
辅助
新辅助
预防性
```

尤其适合：

- 不能手术的局限肺癌
    
- 局部晚期

- 骨转移疼痛
    
- 上腔静脉阻塞
    
- 咯血

敏感性：

```text

>
鳞癌
>
腺癌
```

# 三十一、肺癌三级预防

## 一级预防

> 病因预防。

核心：

```text
戒烟
减少污染
减少职业暴露
健康生活方式
```

## 二级预防

> 早发现、早诊断、早治疗。

重点：

## 三级预防

> 已经患癌后的治疗和康复。

目标：

- 减少并发症
    
- 防止恶化
    
- 减少残疾
    
- 提高生活质量
    

教材将肺癌预防分为病因预防、临床前早筛和临床/康复性三级预防。
